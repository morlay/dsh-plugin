# 离线桌面产物由本仓库自己的打包器产出，不直接用上游桌面应用

状态：已采纳——工作区的桌面形态由 `zephyr desktop dev` / `zephyr desktop bundle` 打（`@morlay/zephyr-desktop-bundle` 插件 + `@morlay/zephyr-desktop-shell` 壳）
背景：诉求是把**一个工作区**打成目标机器上不再联网、不再拉依赖就能启动的桌面目录；产物给自己 / 内测用，不追求分发合规。上游仓里那两个桌面 app（`desktop` 与 `desktop-host`）满足不了两条：前者绑着自己的发行物（app 身份、更新器、签名与安装包流程），后者是 `private` 包；而且本仓库的上游 patch 阶段把上游的 app 目录整棵摘掉了（[`vendor/steps.ts`](../../../../../vendor/steps.ts) 的 `rm` 那几步），vendor 里没有那份应用。

**决定**

桌面形态 = **与 web 同一份 provider 清单** + 本仓库的构建、打包与壳：

- 构建三步全在 [`zephyr build`](../../../../zephyr/zephyr-cli/src/build/builder.ts)：静态面（`vite build`）→ 运行时闭包（`pnpm --filter <app> deploy --prod`）→ 入口（rolldown 打成单文件 `entry.mjs`，第三方留在闭包里）。
- 打包只做装配与归档（[`bundle.ts`](../../src/commands/bundle.ts)、[`packager.ts`](../../src/packager.ts)）：每次都先重建（旧产物与源码是否一致判不出来），再 `pnpm --filter @morlay/zephyr-desktop-shell deploy` 出 app 目录、宿主闭包经 `afterPack` 落 `Resources/runtime`、`electron-builder` 以 `dir: true` 出**应用目录**（不产安装包、`mac.identity: null` 不签名）。
- 壳是**单进程**：直接 import `Resources/runtime/entry.mjs` 起同一棵行树，不自起第二个宿主进程。

**考虑过的选项**

| 选项                                         | 否掉的理由                                                                                   |
| -------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 直接用上游那个桌面 app                       | 那是官方发布态应用，打包与更新流程绑在它自己的发行物上；宿主包 private；且它已不在 vendor 里 |
| 为桌面另写宿主与启动逻辑                     | 第二套后端启动路径，与 web 分叉，升级要维护两份                                              |
| 复用上游 host、自研壳但保留两进程 + 字节管道 | 「窗口先出、宿主后到」会留一个白窗口；两棵树的诊断也拍不到一起                               |

**后果**

- 产物落 `<工作区>/node_modules/.zephyr/`（[`layout.ts`](../../../../zephyr/zephyr-cli/src/layout.ts)）：`dist/`（静态面）、`runtime/`（闭包 + `entry.mjs`）、`app/`（打包产物）。asar 打开，只有 `*.node` 拆到 `app.asar.unpacked`；静态面与 `desktop.json` 走 `extraResources`。
- `electron` 与 `electron-builder` 是**可选 peer**：不装也能装配，真到打包那一步才明确报缺。
- 闭包按 workspace 现状装，所以包里仍是**源码面**的 `.ts`；壳与宿主靠 [`@morlay/dsh-oxc-node`](../../../../boot/dsh-oxc-node/package.json) 现场转译（见[债务 20261110-闭包里的包仍是源码面](../../../../zephyr/zephyr-cli/.agents/debts/20261110-闭包里的包仍是源码面.md)）。
- 打包器与 CLI 当前都是 `private`（壳可发布）：工具只在仓库内用，工作区通过 `plugins: [...provideDesktopBundle()]` 把两个子命令挂到 `zephyr` 上（[例](../../../../../apps/zephyr-custom/zephyr.config.ts)）。两包分工与壳的功能面见[设计 桌面两包](../designs/20261110-桌面两包与单进程壳.md)。
