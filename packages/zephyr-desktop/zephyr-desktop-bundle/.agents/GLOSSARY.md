# 桌面术语表

一份桌面形态的词，只放**定义**；用法与取舍见[设计 桌面功能面](./designs/20261114-desktop功能面.md)，包的门面见 [README](../README.md)。

## 词

| 词                            | 定义                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | 别处怎么引用                                                                                                                               |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 桌面形态                      | 应用以 Electron 启动、宿主行与壳在**同一个进程**里的运行形态（`zephyr desktop dev` / 装出来的应用），区别于 `zephyr dev` 与 `zephyr preview` 的浏览器形态                                                                                                                                                                                                                                                                                                                                         | 层设计说「四种运行形态」时它就是一种；不另造「桌面模式 / 客户端形态」                                                                      |
| 桌面身份                      | 工作区配置 `desktop` 段的值：`id`（反向域名，也是数据目录名）、`name`（显示名）、`icon`、窗口初始尺寸；打包后落成 `Resources/desktop.json`                                                                                                                                                                                                                                                                                                                                                        | 壳与插件只读它的字段；字段的定义权在 `zephyr-cli` 的配置契约                                                                               |
| 桌面插件                      | `@morlay/zephyr-desktop-bundle`：往命令树追加 `desktop dev` / `desktop bundle`，并把工作区打成应用目录                                                                                                                                                                                                                                                                                                                                                                                            | 装配面只写 `plugins: [...provideDesktopBundle()]`                                                                                          |
| 壳                            | `@morlay/zephyr-desktop-shell`：Electron 主进程那一侧——窗口与状态、产品菜单、单实例、导航判据、preload 桥与生命周期                                                                                                                                                                                                                                                                                                                                                                               | 「原生能力归壳」指的就是这一份；壳不读工作区配置                                                                                           |
| 打包期字段                    | 只有打包时才出现、运行期壳不读的字段：asar、`afterPack`、`extraResources`、签名与更新源                                                                                                                                                                                                                                                                                                                                                                                                           | 出现在 `electronBuilderConfigOf`；壳不引用它们                                                                                             |
| 页面端口                      | 宿主 dev server 的端口（`http://127.0.0.1:<端口>`）：它是**页面存储的身份**，不是「一个端口」。粘在 `<userData>/page-port`；被外部进程占着时报错而不换端口，`--port` 是唯一会改 origin 的显式出口                                                                                                                                                                                                                                                                                                 | 说「端口被占」时指这条规则；别说「换个端口重试」，那等于换一份页面存储                                                                     |
| 窗口状态                      | 上次关窗时的位置、尺寸与最大化标记，存在 `userData/window-state.json`；与桌面身份（部署数据）分开：配置管第一次，状态管之后                                                                                                                                                                                                                                                                                                                                                                       | 需要「记住用户拖动」时说窗口状态，别说「窗口配置」                                                                                         |
| 桌面用户数据（`userDataDir`） | Electron 的 `userData`（Chromium profile）：页面存储（localStorage 与页面 shim 的 IndexedDB）、窗口状态、快捷键配置、GPU cache，以及粘住的页面端口 `<userData>/page-port`。它是**桌面侧部署值**：由 `zephyr-desktop-bundle` 一处算出（dev 默认 `<appData>/<desktop.id>/dev/electron`，bundle / preview 默认 `<appData>/<desktop.id>/electron`，test 用临时目录），经 `--user-data-dir` / `ZEPHYR_DESKTOP_USER_DATA` 显式交给壳（显式值优先），壳只 `app.setPath`；**不进 `AppEnv`**，也不是数据根 | 说「桌面用户数据」指这一份；宿主侧的数据（会话 / 设置 / 凭证）在数据根 `dataDir`，两者分开：删它=重置页面与窗口状态，删数据根=重置宿主数据 |
