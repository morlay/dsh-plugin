# 基础面暂时内联而不是装配行

状态：已采纳（暂时形态，恢复成装配行的条件写在「后果」里）

背景：本包（`@morlay/dsh-client-ui-primitives`）的 client 半是**库**：样式层（`styled` / `Token` / `dsw`）、
引用解析与渲染、设置表单原语、按行 schema 生成配置页的组件与模型。它一度作为装配行
（行 id `ui-primitives-fork`，清单里带 `dsh.client.platform` / `inject`）被每个用到它的 bundle 各插一次
（`@morlay/better-session` / `session-mode-profile` / `sandbox-profile` / `ollama-provider-profile`），靠 Loader
对同 id 的幂等复用收敛。

三件事让它更适合当库而不是行：

- **它是随消费方一起进页面的代码**（样式与组件），不是一项常驻服务——每个消费方的 client 半都要 import 它；
- **它的装配面只有一份**（`schemaFormHints` 服务、`settings.schema-form.form` / `field` 槽、`plugins.row.config`
  的按行注册），却要由"谁在场"决定谁触发；
- **每个 bundle 都要插一行**，装配清单里因此多出一条与 bundle 职责无关的重复行。

**决定**

client 半不再作装配行：`tsdown.config.ts` 用 `client: false` 关掉「CJS 单文件工厂」形态，改出普通 ESM 库产物
（`./client` 发布态指 `dist/client.mjs`），清单里标 `dsh.client.inline: true` 让 devkit 的 client 行判据把它当
**内联库**（不再 external、不要求 `dsh.client.platform` / `inject`）；四个 bundle 的 patch 都不再插它。

装配入口 `apply` 由**内联它的每个 client 行**调用（`dsh-session-mode` / `dsh-sandbox-local` /
`dsh-web-search-ollama` / `ui-conversation-message-actions` / `ui-conversation-manager`），实现侧按两条来去重：

- `ctx.inject([...inject], …)`：调用方不必自己排服务顺序，依赖到齐才装配；
- `scope.get("schemaFormHints")` 已在场就返回：同一运行时只装配一次（多份副本各带一份代码，只有第一份生效）。

~~`styling` 单例走全局键 `Symbol.for("@morlay/dsh-client-ui-primitives/styling")`：多份副本共享同一份样式表与
注入状态。~~（已作废：css-in-js 层已删，样式改上游那套 CSS Modules，同一份 `<style data-plugin-css>` 天然只注入
一次——见 [ADR-本包样式改用上游那套 CSS Modules](./20261003-样式改用上游的CSS-Modules.md)。）

**考虑过的选项**

- **保留装配行，只把样式层拆出来内联**：装配行与库两个出口并行，消费方仍要在 `dsh.client.inject` 里排它——
  重复行没消掉，只是换了个名字。
- **让每个消费方在清单里写 `inline: [...]`**：构建与开发态（`dev-client-bundles` 现场打包）都要各自维护这份
  名单，漏一处就是「页面 require 不到模块」或「注册两次」；标在**被内联的包自己**的清单上，一处生效。
- **去掉 `exports["./client"]` 换成别的出口名**：import 路径全要改，恢复成行时再改回来——比标 `inline` 贵。

**后果**

- 消费方少一条装配行：`dsh.client.inject` 里不再排它，四个 bundle 的 patch 各删一行。
- **多份副本是常态**：同一页面上每个消费方产物里各有一份本包代码，判据是「装配只发生一次、样式只有一份」——
  由本包 `apply.spec.ts`（多份副本只装配一次 / 服务已在场就不再装配）与 `styling.spec.tsx`（模块副本共享单例）
  守着；`just build` 的产物判据（`window.__ModuleLoader__.load` 只出现一次）不再是本包的事（它不再产工厂）。
- **发布态出口是库产物**：`dist/client.mjs`（ESM，无模块注册外壳）——内联它的产物不能再嵌一个工厂。
- **恢复成装配行**（将来若要）：`client: { name, entry }` + 清单写回 `dsh.client.platform` / `inject`，
  并让至少一个 bundle 插回那一行；消费方的 `installUiPrimitives(ctx)` 调用可留（幂等，重复无害）。
