# CONTEXT

工具按需注入的词汇。只服务 `packages/preset/dsh-tool-gating/`。

| 词         | 含义                                                                                   |
| ---------- | -------------------------------------------------------------------------------------- |
| 档位       | 当前允许调用的能力组 = 基础组 + 已启用组。按 surface 上的记录重建与重放                |
| 起始档位   | 会话开始时的档位（`config.initial`）；模式之间的差别就是它                             |
| 模式       | 一个 preset 的呈现：`standard`（起始只有基础组）与 `collaboration`（起始含协作编排组） |
| 组         | 档位的单位：一组工具 + 一整段该组的用法提示（`guidance`）；定义在 `src/groups.ts`      |
| 基础组     | `base`，任何档位都可调用的组，不记为「已启用」                                         |
| 启用       | 模型调用 `enable_tools` 把某组并入档位（只增）                                         |
| 切换       | 用户用 `/tools` 设定档位（集合语义，可增可减）                                         |
| 未归组工具 | 不属于任何组的工具：不归档位管，一律放行                                               |
| 能力目录   | 给模型看的中文清单：各组的中文名、用途、工具名与启用状态                               |
| 按组提示   | 启用某组时随组给的一整段中文用法提示；替代上游逐个工具的说明                           |
| 忽略清单   | `IGNORED_SECTIONS`：被遮蔽的上游工具说明 section（静态清单，不随档位变）               |
| 遮蔽       | 在 agent scope 注册同名空文本 section，使忽略清单里的说明不进提示词                    |
| 短描述     | 覆盖上游 `description` 的一行中文（只讲做什么）；参数留在 schema、用法留在按组提示     |
| 元工具     | `enable_tools` 自身：注册在 preset scope，任何档位下都可调用                           |
