# 按 schema 自动生成行配置表单与字段槽注入

状态：已实现——本包给模型与渲染体，配置入口由调用方决定。
范围：`packages/zephyr/zephyr-ui/src/client/schema-form/`（投影、草稿、行视图、提示面、槽契约）与它用到的设置表单原语。
非目标：host 的 schema 投影与 `mutate` 语义（上游 settings）、槽位的实现与授权（上游 `ui-slots` / `ui-renderer`）、具体域的配置项与文案。
关联：[ADR-本包是内联库](./../adrs/20261001-暂时内联而不是装配行.md)、[ADR-样式走上游的 CSS Modules](./../adrs/20261003-样式改用上游的CSS-Modules.md)、[债务 判别式行 Config 要靠顶层 volatile 才被 describe](./../debts/20260924-判别式行Config要靠顶层volatile才被describe.md)、[如何验证](./../standards/how-to-verify.md)。

## 一、决定

| #   | 议题         | 决定                                                                                                 | 一句话理由                                                             |
| --- | ------------ | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 1   | 表单从哪长出 | 本包给 `SchemaFormController`（一行 schema → 页读数）与 `SchemaForm`（渲染体）；**配置入口不归本包** | 行入口要读 `plugin-manager` 的 bundle 行清单，本仓库不接这一面         |
| 2   | 数据面       | schema 用 host 已投影好的 `describe()` 视图，值走 `ctx.configForms` 的共享表单                       | 本包不新增 host 面，也不引第二个数据面                                 |
| 3   | 渲染形态     | 行式 JSON 结构视图：行号列固定、缩进只推内容、添加输入跟容器闭合括号同一行、值行内编辑               | 结构一眼可见，编辑不离开这一行                                         |
| 4   | union 的呈现 | 按**选中变体**决定形状与值，行尾给变体切换：带 tag 的写标签值，无 tag 的写目标变体的空值             | 只按对象容器画，`access` 这类字段的值会整块丢掉                        |
| 5   | 选择器       | 字段有候选（字面量集合的 `union`，或提示面注册的候选值）就画下拉；`dependsOn` 的兄弟字段一变就重算   | 候选是运行期事实（选服务商 → 它的模型），schema 写不出来               |
| 6   | 自定义输入   | chain 槽 `settings.schema-form.field`：按 `role` 或 `ns + path` 认领，未命中落默认控件               | 一个机制同时承载「role 默认路由」与「path 精确覆盖」                   |
| 7   | 子槽声明     | 字段槽的 children 声明收在 Factory `settings.schema-form.form` 上                                    | slots 的 children 声明 per key 只能一次，N 个行项逐行声明同 key 必冲突 |
| 8   | 写盘         | 暂存 + 保存：按 path op **一次** `mutate` 并带 revision 栅栏                                         | 与上游表单壳形态一致，高频字段不会产生多次写                           |
| 9   | 装配         | 不是装配行：`apply(ctx)` 由内联它的 client 行调用，按提示面在场幂等                                  | 见 [ADR-本包是内联库](./../adrs/20261001-暂时内联而不是装配行.md)      |

## 二、现状事实

`src/client/schema-form/`的分工：

| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| `controller.ts`                 | `SchemaFormController`（per ns 的页读数与动作）、`projectRoot` / `canRender` / `addableAt` / `fieldKey` / `optionsFor`                                                               |
| `draft.ts`                      | `SchemaDraftModel`（草稿 → path op）、`failureOf`（把校验错误收成 `ValidationFailure`）                                                                                              |
| `lines.ts`                      | `editorLines` / `visibleFields` / `containerShape`（行式视图的输入件）                                                                                                               |

| `hints.ts`                      | 提示面：`SchemaFormHintsDefault`、`SERVICE_NAME = "schemaFormHints"`、`schemaFormHintsOf(ctx)`                                                                                       |
| `slot-contract.ts`              | 槽契约：`SchemaFieldOwnerProps` / `SchemaFieldSelect` / `SchemaFormProps`（入口处的声明合并）                                                                                        |
| `locales.ts` / `labels.ts`      | 命名空间 `settings.schema-form` 的字典与字段 key 的兜底文案                                                                                                                          |
| `geometry.ts`                   | 行内几何常量（`ICON_SIZE`）                                                                                                                                                          |
| `TruncatedTooltip.tsx`          | 只在真的被截断时挂官方 `Tooltip`                                                                                                                                                     |
| `testing/`                      | `FakeScope` / `fakeDescribe` / `discriminatedConfig` / `stubResizeObserver` + `notifyResize`                                                                                         |

- **装配面**：`schema-form/index.ts` 的 `apply(ctx)` 先挂提示面（`ctx.root.reflect.provide(SERVICE_NAME, …)`），再 `locale.register`，再 `slots.registerFactory`；顺序是幂等的前提。
- **本包不注册 `plugins.row.config`**：行配置入口要读 bundle 行清单，本仓库没有这一面。
- **提示面读法**：消费方用 `schemaFormHintsOf(ctx)` 按字面名读，不能 `inject`（本包没有 `provide` 清单，`ProvidersCoverage` 会在编译期拒绝）。

## 三、模块边界与接口

| 模块                                | 拥有（职责与不变量）                                                            | 不拥有（明确排除）                   | 依赖方向                                    | 接缝 / 适配器                  |
| ----------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------ | ------------------------------------------- | ------------------------------ |
| 字段树（`schema-node.ts`）          | schema → `FieldNode` 的投影、meta 归一、只读原因、递归收口                      | 值；文案；槽位                       | ← schemastery 的 `toJSON` 形状              | 纯函数                         |
| 页读数（`controller.ts`）           | describe 视图 + 共享表单 → `SchemaFormState` / 动作；`projectRoot` 的根形状判据 | host 的投影与写盘；槽位注册          | ← `configForms` / `settingsSchema` / 提示面 | `SchemaFormController`         |
| 草稿（`draft.ts`）                  | 草稿编辑 → path op；整段校验；非法草稿挡保存                                    | revision 栅栏（host 的 `mutate` 管） | ← `ConfigForm`                              | `SchemaDraftModel`             |
| 行视图（`lines.ts` + `Editor.tsx`） | 行序、折进、折叠、行内控件与添加入口                                            | 布局样式（`.module.css` 里）         | ← 页读数                                    | 纯函数 + 渲染                  |
| 提示面（`hints.ts`）                | 文案 / 候选键 / 候选值的三类注册与路径匹配                                      | 读数的来源（业务注册）               | ← 根 ctx                                    | 服务契约 `SchemaFormHintsFace` |
| 槽契约（`slot-contract.ts`）        | 字段槽与表单 Factory 的 props 形状                                              | 槽位实现与授权（上游）               | ← 上游 `ui-slots` / `ui-renderer`           | chain 槽 + Factory             |
| 装配（`schema-form/index.ts`）      | `apply` 的注册顺序与幂等                                                        | 谁在哪儿打开页面                     | ← 上面各模块                                | `apply(ctx)`                   |

**接口**：`new SchemaFormController(ns, deps)` 与 `canRender` / `projectRoot` / `addableAt`（装配面用它组注册项）；`SchemaFormController.face()` 给 `{ hooks: { schemaForm }, ...actions }`；动作是 `set` / `setText` / `clear` / `appendItem` / `removeItem` / `addKey` / `removeKey` / `save` / `revert` / `discard`（`save` 是唯一写盘点）；槽注册项 `{ name, select, priority?, inject?, locale? }`，`select` 返回 `matched` 或 `null`（`null` 才是不认领）。
不变量：字段槽的 `path` 总是具体路径（模板路径只为注册而写）；`save` 是唯一写盘点；`apply` 幂等（提示面在场即返回）。

**深度**：删掉这一面，每个插件都要自己写一遍 schema → 控件、草稿 → path op、行视图与截断浮层——同一套逻辑复制 N 份。

## 四、行为与边界

- 正常：`describe()` 给 schema 与值 → `projectRoot` 判根形状 → 字段树 + 草稿 → 行视图；编辑只改草稿，`save` 一次 `mutate`。
- 错误：非法输入在行内给消息并挡保存（`failureOf` 收成 `ValidationFailure`）；host 的 revision 栅栏失败时保留草稿。
- 取消：`discard` 丢草稿，不发写。
- 生命周期：`controller.dispose()` 释放订阅；schema 重新 describe 时只换字段树，草稿与 store 不动。
- 并发：候选读数是同步的（投影发生在渲染帧里），异步来源由业务取好再注册、变了调 `refresh()`。
- 边界：secret 位只有「已配置」状态（`••••••`），不给值回传。

## 六、取舍

- 否掉「每个插件自写配置页」：同一套 schema → 控件逻辑复制 N 份，字段增删要改 N 处。
- 否掉「注册到 `settings.plugins.tab`」：与现有卡片落点不同，且要再造一份入口；行配置页才是「这一行的 Config」的位置。
- 否掉「字段槽的 children 声明放在每个行注册项上」：slots 硬约束，同一 key 只能声明一次。
- 否掉「让业务方各自声明字段槽」：声明权与渲染授权绑在注册项上，业务方无法为别人的行声明。
- 否掉「用 cordis 服务承载字段文案或自定义控件」：跨插件 value import 被 client bundle 的 purity gate 禁。
- 否掉「即时写」（控件变更即 mutate）：与上游表单壳形态不符，高频字段会产生多次写与多次 revision 冲突。
- 否掉「fork 设置表单原语」：上游那份就是 CSS Modules，re-export 更省且同源。

## 七、不做与已知债

- 数组项重排与字典键重命名：只做追加与删除（键名只读显示）。
- 字面量 `union` 顶层的 Config（整段是一个标量）：写盘会变成整段替换，不支持。
- 判别式行 Config 要靠顶层 `.volatile()` 或包一层对象才被 host 描述出来：见[债务](./../debts/20260924-判别式行Config要靠顶层volatile才被describe.md)。
- 不做异步候选：要触网发现候选由业务包自己取好再注册。

## 八、开放问题

- 行配置入口（`plugins.row.config`，key = `<bundle 包名>#<行 id>`）在本仓库**没有落点**：它要读 `plugin-manager` 的 bundle 行清单，这一面本轮不接。接回来时按 `SchemaFormController` + `SchemaForm` 组装注册项即可，模型与组件不必改。
- `autoGenerate` 有 host 侧的写面但本包不消费：行入口不在本包之后，这个开关没有客户端落点。
- 变体切换只写「那一支的代表值」：不做逐字段迁移（把旧支的值搬到新支）。
