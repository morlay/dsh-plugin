# dev 收尾后仍有残留句柄

状态：接受中（已用显式退出兜住）——`zephyr dev` 收尾完成后进程不会自然结束。

位置：`packages/zephyr/zephyr-cli/src/commands/dev.ts`（`process.exit(0)` 兜底）、`packages/zephyr/zephyr-dev` 的行 dispose。

**现象**

`just custom dev` 收到 SIGINT 后，日志打出「收到退出信号，开始收尾」与「已退出」（`session.close()` 已返回、端口已释放），
但进程仍在，`pgrep` 能看到。收尾完成后 `_getActiveHandles()` 剩 6 个：

```
Server, Socket, Socket, Socket, ChildProcess, ChildProcess
```

**为什么不现在修**

收尾本身是完整的（树按逆序 dispose、http 端口关闭、vite 会话结束）；这些句柄的 owner 在第三方行里
（vite 的 ws server、esbuild/rolldown 的子进程一类），要逐个确认哪条 `onDispose` 漏了关。用户侧的
症状（按 Ctrl+C 退不出）已经由 `process.exit(0)` 兜住，代价是「优雅退出的最后一步靠强退」。

**销账条件**

`app.dispose()` 返回后 `_getActiveHandles()` 只剩 stdio（0/1/2），此时删掉 `process.exit(0)` 与这份债。
