# preset 行清单归还上游

状态：已采纳

背景：本包曾把 web-app 的四份 shipped preset（`standard` / `ptc` / `minimal` / `cordis`）逐行复制进来，只删掉 `delegation`
组里的 `tool-subagent-control` / `tool-subagent` / `tool-subagent-fork`。那条改动的理由在当时成立：Agent Teams 用**同名工具**
接管直连委派，两套并存会互相遮蔽（见[ADR preset 行清单归本包](./20261030-preset行清单归本包.md)）。

上游 0.2.2-rc.2 把这个前提翻了过来：Team 不再提供同名委派工具，只提供任务板（`team_task_*`）与 `team:policy`，
而队友的创建与联系**就是**标准的 `subagent` / `subagent_fork` / `send_message` / `list_agents` / `interrupt_agent`
（`vendor/deepseek-harness/packages/team/tool-agent-team/README.md` 明写这份组合还需要 `@deepseek-ai/dsh-tool-subagent`
与 `-control`，`team:policy` 正文也直接让模型用 `send_message` 联系队友）。删掉那三行 = 会话里没有 `send_message` 与
`subagent` = Team 不可用。

**决定**

四份 preset 的行清单归还上游 web-app bundle：本包不再复制、不再改行，只按行 id 覆盖 `agent-preset-registry` 的
`config.default = "ptc"`。

**考虑过的选项**

- **继续复制但不再删行**：行为等同上游，却多一份要跟上游逐行对齐的副本（`src/__tests__/patch.spec.ts` 的“逐行复制”守护
  会长期红/绿跳动），收益为零 → 否。
- **继续删行、改用 Team 自己的同名工具**：rc.2 的 Team 已经没有同名委派工具，这条组合根本装不起来 → 否。
- **只删 `tool-subagent` 保留 `tool-subagent-control`**：`send_message` 回来了，但没有 `subagent` 就创建不了队友，
  Team 仍然只剩任务板 → 否。

**后果**

- 得到：会话里同时具备直连委派（`subagent` / `subagent_fork`）与 Team 任务板，两者按上游设计协作；本包少一份随上游漂移的
  行清单副本，`patch.spec.ts` 只剩“生成物同形”与“部署默认 preset”两条守护。
- 放弃：曾经“只给 Team、不给直连委派”的收窄。要恢复那种收窄，得重新引入 preset 副本并停掉 `tool-subagent*`，
  届时 Team 需另配通信面——当前上游没有等价能力。
- 升级时：preset 的漂移由上游 bundle 承担，本包不再需要逐行对齐；若上游再次改变 Team 与委派工具的绑定关系，
  `patch.spec.ts` 的“不声明 preset 行”不会红，需要人工看上游 README。
