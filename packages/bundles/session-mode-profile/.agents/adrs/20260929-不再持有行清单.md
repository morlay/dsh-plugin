# 不再持有行清单（删掉自建的 `mode-switch` preset）

状态：已采纳

背景：本部署曾自建一份 agent preset（`preset-mode-switch`，`config.id: mode-switch`）供两个会话模式拿行清单，代价是
一份**我们自己持有**的上游行清单：上游行升版要人工对齐包名 / 行 id / `config`（`patch.spec.ts` 逐行比对兜着），
计划模式的规则段、工具行的调参（`searchTimeoutMs`、pruner 阈值、`allowParallelInProgress`、`isolate`）也都由我们
维护。模式随后解绑了 preset（[ADR-模式不绑定preset](../../../../profile/dsh-session-mode/.agents/adrs/20260929-模式不绑定preset.md)），
这份自建 preset 只剩"给新会话当默认行清单"一个用途——而这正是官方 shipped preset 的用途。

**决定**

删掉 `preset-mode-switch` 声明与它引用的行数据：`@morlay/dsh-tool-guidance` 不再发布功能行清单出口
（`TOOLKIT_ROWS` / `TOOLKIT_PRESET_ROWS` / `TOOLKIT_COMPACTION_ROWS` / `TOOLKIT_PLAN_ROWS` /
`TOOLKIT_POLICY_ROWS` / `TEAM_ROWS` / `TOOLKIT_TOOL_NAMES`），`relax-intent` 与 `agent-team` 两个可选出口一并删除；
`@morlay/mydsh-profile` 不再指定 `agent-preset-registry.default`——新会话挂官方 web-app 的默认（`standard`）。
本 bundle 只剩 host 平面的那几行：模式行（按会话收口也在它内部）、`context-assembler`、`subagent` 接管行、`tool-guidance`。

**代价**（都照实钉在判据里，不假装还在）

- **「先读后改」的豁免换了表达**：`fs-intent-relax` 是 preset 行，随行清单一起删除；这份豁免现在由**模式自己的
  policy 名单**表达（`coding.denyPolicies: [fs/edit-intent]`，写路径上的 CAS 安全网留着），见
  [设计 按模式的 policy 拦截](../../../../profile/dsh-session-mode/.agents/designs/20260929-按模式的policy拦截.md)。
- **计划模式规则段变英文**：官方 `standard` 的 `plan-mode` 行带它自己的英文 `section`，我们不能覆盖 shipped preset 的
  `config.plugins`（官方明说整段替换、不合并后续内置变更）。
- **子代理**：官方 `standard` 的 `tool-subagent` 带 `modelSelectionSettings: true`（我们那份刻意不带）。
- **注入面**：官方 `standard` 自带上游 `agent-instructions` 与 `tool-skill` 行——工作区指令与技能目录都由上游注入，
  我们的通道只做装配结果上的文本转换（[设计 通道只做转换](../../../../context/dsh-context-assembler/.agents/designs/20260929-通道只做转换.md)）。
  `chat` 那两条面由 `session-mode` 的收口在 `agent/pre-step` 外层丢掉（`instructions: false` 一条、工具名单推出来的
  `skills: false` 另一条）；代价是官方那两行每步仍重算一次要送的内容，只是结果被丢掉
  （[设计 抑制官方注入面](../../../../profile/dsh-session-mode/.agents/designs/20260929-抑制官方注入面.md)）。
- **子代理的中文回报指引不限 preset**：装配里**不传** `localizedReturnGuidancePresets`——不配名单 = 官方四个 shipped
  preset 与还没绑 preset 的会话都用我们的中文文案；判据是 `patch.spec.ts` 里那一行没有 `config`。
- 行清单里没有的工具照旧"收口时自动跳过"：`chat` 的三件在 `standard` / `ptc` / `cordis` 上都齐，在 `minimal` 上
  一件都不剩（`preset-plane.spec.ts` 那条"缺工具的 preset 上目录为空"钉住）。

**考虑过的选项**

- **保留 preset 声明、只把默认改指官方**：自建那份还在名册里，用户可以在 roster 里选到它——等于留着"我们持有的
  行清单"这笔维护债，只是不再默认。
- **把行清单摊回 host 平面**：ADR-模式是preset的会话级扩展 已经否掉（官方把这些行在 host 平面 `disabled`，且有
  `validatePresetPlaneSeparation` 校验一行只属于一个平面）。
- **只删部分行数据**（保留 `relax-intent` / 计划模式契约）：它们必须挂在 preset 的行清单里才能生效，留着出口没有
  消费者，是死代码。

**后果**

- `@morlay/dsh-tool-guidance` 只剩包根（汉化 + 用法分组）与 `./rows`（`toolGuidanceRow`）两个出口，devDeps /
  peers 一并精简；它的"覆盖性"测试（`guidance-inventory.spec.ts`）本来就以 shipped `standard` 为基准，现在更贴题。
- `@morlay/mydsh-profile` 只覆盖值与行为（locale、欢迎提示、默认模型、对话视图），不指定行清单来源。
- 判据：本 bundle 的 `patch.spec.ts`（装配里不再有 preset 行、子代理那一行没有 `config`、三个模式都不写 `presetsOnly` 与
  `denyTools`（`chat` 写着 `allowTools` 收窄到三件）、`coding` 的 `denyPolicies` 进 config）、`dsh-session-mode` 的
  `preset-plane.spec.ts`（真装配：会话挂
  官方同形行清单时 chat 三件、通道注入为 0、切模式不换 preset、缺工具的 preset 上目录为空、policy 拦截成对判）。
  曾经那条真 profile 探针（会建会话）已删除——这些面都在包内真装配用例里钉住了。
