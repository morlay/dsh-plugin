# preset 改用上游声明式行，退出目录物化

状态：**已作废**（2026-09-24 起整套形态被 [ADR 模式不再是 Cordis 子树](./20260924-模式不再是cordis子树.md)
取代：模式不再是 Cordis 子树，官方 agent preset 那一套也整个退出部署）。沿革：2026-09-23 起其中"官方四个
preset 行不动"这半先被取代——它们已在 [`@morlay/dsh-profile`](../../../dsh-profile/README.md) 的 patch 里
`disabled: true`。

背景：上游 0.1.7 拆掉了 `@deepseek-ai/dsh-agent-presets`（我们的 preset 来源）：

- preset 现在是**一行** `@deepseek-ai/dsh-agent-preset`，`config.plugins` 就是该模式的装配行；
- registry（`@deepseek-ai/dsh-agent-preset-registry`）**既不扫目录也不收路径**，只认 `default` 一个配置项；
- 官方 shipped preset 变成 dsh-web-app bundle 的 patch 文件（`presets/*.patch.yml`）里的行
  （`preset-standard` / `preset-ptc` / `preset-minimal` / `preset-cordis`），选择器看到的就是这些行。

我们那套「生成 `dist/presets/` 目录 + 用 `!!js` 把 roots 指过去 + 桌面形态把目录物化到 dsh 包内挂载点」
因此整体失去依托。

**决定**

preset 改成这份 bundle patch 里插入的两行 `@deepseek-ai/dsh-agent-preset`：`preset-coding`（id `coding`）
与 `preset-chat`（id `chat`），registry 的 `default` 指向 `coding`；**官方那四个 shipped preset 行
（`preset-standard` / `preset-ptc` / `preset-minimal` / `preset-cordis`）不动**——它们是各自 scope 里的完整
composition，与我们的模式并存、可选（2026-09-22 决定：不去禁用它们，少一处跟着上游 preset 名单走的耦合）；
`dist/presets` 生成、`dsh.configTrees` 声明与 dsh-desktopify 的 preset 物化（`discoverPresetMounts` /
`materializeAgentPresets` / `dsh.desktop.agentPresets`）一并删除——三种形态（dev / web / 桌面）现在
读的是同一份行，不再有桌面专属的目录挂载点。

**考虑过的选项**

- **覆盖官方 `preset-standard` 的 `config.plugins`**：省掉自己插行，但我们的模式会被迫叫 `standard`
  （id 决定展示名与选择器身份），与「这是我们的模式」不符；用户明确要求改名 `coding` / `chat`。
- **按 id 禁用官方那四行**（先前的做法）：选择器里只剩我们的两个模式，干净；但禁用列表要跟着上游的
  preset 名单走（改名/增删就得改我们），收益只是「少四个选项」，2026-09-22 决定放弃。
- **保留目录 roots**：上游已无此能力，registry 不接受路径。
- **桌面形态继续物化一份目录**：上游连挂载点概念一起删了，物化出来没人读。

**后果**

- 模式定义随 patch 走：改 `tool/presets/*.ts` → 重新 build 即改 `cordis.patch.yml`；不再有
  「构建产物目录」这一层，`generated-presets.spec.ts` 与目录守卫一起删除，模式与清单的一致性由
  `patch.spec.ts` 断言（每个模式一行、config 逐项等于清单）。
- **改名有代价**：会话日志里记的是 preset id，恢复旧会话时 registry 按 id 找定义，找不到即
  `agent-preset/not-found`——用 `standard` 建过的旧会话需要重选模式（或保留一个 id 为 `standard` 的
  兼容定义；当前不做，真需要时再插一行别名即可）。
- 选择器里除了 `coding` / `chat`，还留着官方四个模式：它们装官方自己的工具与提示词（含官方 `tool-skill`），
  不装我们的注入行——选到就是官方原味，默认不选它们。
- 桌面不再需要「先把目录物化进 dsh 包」这一步：启动期的目录拷贝、`dsh.configTrees` 校验与相关测试
  全部退出 dsh-desktopify。
