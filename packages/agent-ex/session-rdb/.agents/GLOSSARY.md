# 会话编辑（`better-session`）

就地编辑、撤回、派生与重放怎么称呼：**本包定义编辑语义**，数据面的词（会话 / 轮次 / 闭合边界 / live 与 cold）由 [`dsh-session`](../../../agent/dsh-session/.agents/GLOSSARY.md) 定义，这里只引用。
上下文边界见[定义权地图](../../../../.agents/GLOSSARY-MAP.md)。

## 术语

### 编辑与派生

**就地编辑**：
编辑 / 重试 / 重掷的语义：截断到闭合边界后重写**同一会话**，会话标识不变。
_避免使用_：原地修改、in-place

**撤回（recall）**：
把已落定的用户消息从会话截断到它之前，文本交回输入框由用户改完再发——只截断、不重写、不重放、不产生版本效果。**尚未落定的排队消息**用同一个词、成本不同：把它移出队列、原文交回输入框，不触碰会话记录，所以不需要确认。
_避免使用_：撤销、undo

**分支（fork）**：
从任意闭合边界派生**新会话**（纯追加，不触碰源会话）——唯一产生新会话标识的操作。
_避免使用_：复制会话、clone

**seed（种子）**：
派生会话的初始事件前缀：边界前缀，加可选的种子后缀（手工补的回合）。
_避免使用_：初始状态、initial state

**重放（replay）**：
把排队的用户输入经 agent 的后续输入通道驱动重放（live 直接排队；cold 先恢复会话）。
_避免使用_：重生成、regenerate

### 服务面

**会话编辑组（sessionEditor）**：
一组端点（编辑 / 重掷 / 重试 / 截断 / 撤回 / 派生），由本包的宿主半实现，浏览器半经端点调用——不直读库表。
_避免使用_：编辑接口、action 组

**归档集（archive set）**：
本包**只读引用、不拥有**：读侧是「一组被归档的会话」，真相是 workspace 域的 global（`archivedSessionIds`），本包把它写穿到会话行的归档标记并按它过滤；归档 / 取消归档的**动作** owner 也在 workspace 域（`uiWorkspace`），本包不提供第二个入口。写侧的定义等 workspace 域自己写下来再登记（[定义权地图](../../../../.agents/GLOSSARY-MAP.md) 上只有这一行）。
_避免使用_：归档列表、收藏夹

### 运维与检索

**数据体检（一致性检查）**：
只读地比派生统计与事件行，只报「该有的少了」这一方向的漂移（五类：token 漏记 / 计数漏记 / 孤儿用量行 / 引用标记漏记 / 种子长度超出日志），不自动修；修法不在这一处——重算归整理（`organize`），读不出来的会话归修复（`repair`）。
_避免使用_：健康检查、校验、纠错

**事件定位**：
在会话内按文本 / 类型 / 角色 / 名称 / 时间找事件，回 seq 窗口与命中片段，不搬事件体——所以读不出来的会话也能定位。
_避免使用_：事件搜索、全文检索

**丢坏尾部 / 整段重写**：
坏会话的两个日志修法（第三个是删除）：可读边界＝从头逐行读时第一条解析不出来或序号断号的行。**丢坏尾部**只丢边界之后的事件，之前的部分原样保留、head 跟着收；**整段重写**按同一界把可读前缀整段重写（截断 / 重写 / head 复位 / 种子长度收缩同一事务）。
_避免使用_：修复（太泛）、截断（那是撤回的动作）

**两段式搜索**：
标题搜索先走**前缀段**（`lower(f_title)` 的范围比较），没命中再退**全文段**（`%x%`）；两段同一个大小写口径，实际走了哪段由 `searchStage` 回报。
_避免使用_：模糊搜索、前缀搜索（只说了一半）

**跨工作区复制**：
把一个会话复制到别的工作区 = 本包 `fork` 出的子会话把 cwd 换成目标工作区路径 + workspace 域的 `attach`；**源会话保留**（复制不是移动），attach 失败撤掉刚派生的子会话。
_避免使用_：移动会话、导入到工作区

一组端点（列表 / 删除 / 导入 / 导出 / 归档编排 / 用量），对话管理页只用它；归档与取消归档仍委托工作区面。
_避免使用_：管理接口、后台任务
