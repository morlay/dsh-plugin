# 会话编辑（`better-session`）

就地编辑、撤回、派生与重放怎么称呼：**本包定义编辑语义**，数据面的词（会话 / 轮次 / 闭合边界 / live 与 cold）由 [`dsh-session`](../../../agent/dsh-session/.agents/GLOSSARY.md) 定义，这里只引用。
上下文边界见[定义权地图](../../../../.agents/GLOSSARY-MAP.md)。

## 术语

### 编辑与派生

**就地编辑**：
编辑 / 重试 / 重掷的语义：截断到闭合边界后重写**同一会话**，会话标识不变。
_避免使用_：原地修改、in-place

**撤回（recall）**：
把已落定的用户消息从会话截断到它之前，文本交回输入框由用户改完再发——只截断、不重写、不重放、不产生版本效果。**尚未落定的排队消息**用同一个词、成本不同：把它移出队列、原文交回输入框，不触碰会话记录，所以不需要确认。
_避免使用_：撤销、undo

**分支（fork）**：
从任意闭合边界派生**新会话**（纯追加，不触碰源会话）——唯一产生新会话标识的操作。
_避免使用_：复制会话、clone

**seed（种子）**：
派生会话的初始事件前缀：边界前缀，加可选的种子后缀（手工补的回合）。
_避免使用_：初始状态、initial state

**重放（replay）**：
把排队的用户输入经 agent 的后续输入通道驱动重放（live 直接排队；cold 先恢复会话）。
_避免使用_：重生成、regenerate

### 服务面

**会话编辑组（sessionEditor）**：
一组端点（编辑 / 重掷 / 重试 / 截断 / 撤回 / 派生），由本包的宿主半实现，浏览器半经端点调用——不直读库表。
_避免使用_：编辑接口、action 组

**归档集（archive set）**：
一组被归档的会话：管理组负责归档编排，底层归档动作仍委托工作区面。
_避免使用_：归档列表、收藏夹

**会话管理组（sessionAdmin）**：
一组端点（列表 / 删除 / 导入 / 导出 / 归档编排 / 用量），对话管理页只用它；归档与取消归档仍委托工作区面。
_避免使用_：管理接口、后台任务
