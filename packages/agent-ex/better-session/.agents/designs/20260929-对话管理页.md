# 对话管理页（侧栏面板的形态、数据位与动作面）

状态：**已实现**——`provideBetterSessionUi()` 装出侧栏「对话管理」页；判据见 `src/ui/conversation-manager/__tests__/**`。
范围：`@morlay/better-session` 的 `src/ui/conversation-manager/**`——页面框架、会话视图与统计视图、`data-*` 标注面，以及它对 `sessionAdmin` 组与 `uiWorkspace` 的依赖；宿主实现（`src/server/session-admin-endpoint.service.ts`）的形状见 [设计 20261106-RDB复用边界与Remote端点形状](./20261106-RDB复用边界与Remote端点形状.md)。
非目标：归档状态的 owner（workspace 域）、会话行的读法（`src/rdb/**`）、消息动作（`src/ui/session-editor/**`，见包 `README.md` 与 `src/ui/session-editor/__tests__/session-editor.store.spec.ts`）。
关联：词义见[会话数据面术语表](../../../../agent/dsh-session/.agents/GLOSSARY.md)（会话 / 轮次 / live）与[会话编辑术语表](../GLOSSARY.md)（归档集在会话管理组一节）；[ADR-归档集管理动作归对话管理页](../adrs/20260918-归档集管理动作归对话管理页.md)。

| 4   | 统计视图      | 一次全库聚合（`sessionAdmin/usage`），换时间范围才重新请求，维度切换本地折叠                                                              | 聚合口径归统计表（`src/rdb/db/stats.ts`），页面只做展示与折叠 |

## 二、现状事实

- **文件**：页面 `conversation-manager-page.tsx`（+ `conversation-manager-page.module.css`）、动作面 `conversation-manager.controller.ts`、wire 客户端 `session-admin-endpoint.client.ts`、视图与槽位 `conversation-manager.view.tsx` / `conversation-manager-page.slot.ts`、字典 `locales.ts` + `conversation-manager-locales.contribution.ts`、数字格式 `format.ts`。
- **装配**：`src/ui/better-session.provide.ts` 的 `provideBetterSessionUi()`，字典与端点客户端先、store / 贡献 / 视图后。
- **页面只读注入面**：`t` + `ConversationManagerFace`（`listRows` / `archive` / `unarchive` / `remove` / `exportZip` / `importZip` / `organizeData` / `loadUsage`）；wire、base64、下载细节全在 controller 里。
- **行形状**：宿主给 `SessionRowsItem`（`sessionId` / `title` / `origin` / `cwd` / `createdAt` / `updatedAt` / `archived` / `workspace`，见 `src/endpoint/session-admin-endpoint.ts`）；页面按 `origin === "subagent"` 判子代理，标题缺省用 session id。
- **框架**：`.page` / `.listPane` / `.pageScroll`（`data-scroll="page"`）/ `.pageContent`（960px 居中列）/ `.pageHeading` / `.filters` + `.filterTabs` + `.filterTab` / `.searchField`；整列一起滚，页面根不滚。
- **会话视图**：视图 chip（会话 / 统计）→ 子代理开关（只在会话视图）→ 搜索行（只在会话视图）→ 列表 → 分页条；行上「归档 / 取消归档」互斥、导出恒有、删除只在已归档行可用（宿主同样守卫）。
- **统计视图**：时间范围 chip（`day` / `week` / `7d` / `30d` / `90d` / `all`，默认 `day`）→ 维度 chip（`overview` / `models` / `sessions`）→ 按会话维度时的「只看子代理」开关；总览两行（全部 / 其中子代理），按模型把人类与子代理的桶折进同一行，按会话取用量前 20。
- **单项口径**：输入（含缓存）· 缓存输入 · 缓存命中率（缓存输入 ÷（输入 + 缓存输入））· 输出 · 推理 · 事件；活动计数（轮次 / 步 / 用户输入 / 工具调用）在总览与按会话的行上都有，按模型的行不显示（事件没有模型归属）。**没有合计项**；排序权重是「输入（含缓存）+ 输出」，不显示。
- **GC**：`organize` 先确认 → 运行期弹窗没有关闭按钮（mask 与 Escape 都走空 `onClose`）→ 回报里给出孤儿会话 / 孤儿事件 / 重算会话数。
- **`data-*`**：`data-view`（页面根）、`data-tab`（chip）、`data-action`（`import` / `gc` / `archive` / `unarchive` / `export` / `remove`）、`data-filter`（`view` / `subagents` / `search` / `usage-range` / `usage-tabs` / `usage-subagents`）、`data-scroll`、`data-session-id` / `data-archived` / `data-subagent`（行）、`data-pagination` / `data-page-current` / `data-page-total`、`data-notice` / `data-failure` / `data-status`（`loading` / `empty` / `failure` / `empty-search`）、`data-usage-view` / `data-usage-tab` / `data-usage-range` / `data-usage-key` / `data-usage-cell` / `data-usage-value` / `data-usage-status`（`loading` / `error` / `empty`）。
- **几何**：960px 上限、28px 上内距 + macOS 顶栏让位、`.status` 的整屏居中都在 CSS module 里；jsdom 没有布局，用例只钉结构与类名。

**接口**（调用方要知道的）：

- `listRows(request)` 的 `page` 从 1 起、`pageSize` 缺省 20；返回 `{ items, total, page, pageSize }`，页面按 `total` 算页数。
- 动作失败一律抛 `ConversationManagerRequestError`（带宿主 `code`）；页面用 `SESSION_NOT_ARCHIVED` / `SESSION_LIVE` / `SESSION_NOT_FOUND` 选文案，其余显示原文。
- 删除只对已归档行可用（页面禁用 + 宿主守卫两道）；归档 / 取消归档委托 `uiWorkspace`，本页不提供第二套。

## 四、行为与边界

1. **正常路径**：进入页面拉第一页 → 行按最近活动降序（宿主排序）→ 动作成功后重拉当前页。
2. **搜索**：输入停 250ms 才发请求并把页码重置为 1；有查询时出现清空按钮，点了清空并还原列表；搜索无结果时框架留着，空态落在列表位置。
3. **分页**：每页 20 条，翻页即重新请求；页数按 `total` 算，当前页被夹在范围内。
4. **子代理**：默认不列（真实库里占多数，既不可删也多数无意义）；勾选后真全量并带标记。
5. **错误**：读列表失败 → 整屏失败态（`role="alert"`）；动作失败 → 行上方提示，弹窗收掉，列表不重拉。
6. **GC**：确认后进入不可关闭的运行期弹窗；成功后提示三项计数并重拉列表。
7. **统计**：进入统计视图时拉一次（默认本日、总览）；换范围带参数重新请求；维度切换不请求；失败时给原因，已拿到的报告不被清空。
8. **取消与并发**：页面不取消在途请求——请求失败只落到提示行；同一时刻只允许一个删除确认或一个 GC 流程。

## 六、取舍

- **不借官方 `session/list`**：它按部署策略排除已归档、且没有标题与最后活动时间；两条路混用会让「缺席即删除」的语义与归档集判定互相污染。
- **不做前端过滤 / 分页**：成本随会话数线性增长，后端已经有完整语料与分页参数通道。**例外**是统计按会话维度的「只看子代理」——数据已在手上，过滤不产生新请求。
- **页面框架不自造原子**：上游没有共享的 `pageHeading` / `filterTabs` 原子，各家一级页面在 CSS Modules 里写同一套度量；本包是唯一消费者，照写一份比往基础面加导出便宜。
- **按模型不拆子代理**：模型行的价值是「哪个模型花了多少」，子代理用的是同一个模型，拆行只会把同一模型的成本打散。
- **不做常驻刷新**：这是只读面板，动作成功后重拉一次即可。
- **不用 tab 条表达视图切换**：切换与过滤都是筛选 chip（`aria-pressed`），与上游一级页面的视觉一致。

## 七、不做与已知债

- 排序只有「最近活动在前」一种，没有分组与批量操作。
- 子代理会话可见后仍不可删除（它们未归档）——要删先归档，符合「删除仅限已归档」的口径。
- 统计是一次全库聚合，只在进入统计视图时请求；按会话的行是各会话自己的日志口径（fork 子会话含继承前缀），所以各行之和 ≥ 总量。
- 导入只接受含会话日志 artifact 的 zip；导出只导出该 artifact，不含附件等旁路数据。

## 八、开放问题

- 统计视图按会话维度只取前 20：超过时目前只能靠时间范围收窄，要不要给分页或导出。
- 孤儿 GC 的进度：现在只有不可关闭的等待弹窗，长库上的耗时不可见。
