# 就地编辑重写同一会话而非新建会话

状态：已采纳

背景：用户对「编辑这条消息」的期望是改掉它本身，而不是开一个新会话——产品语义对齐
[dsh-message-edit](https://github.com/Moeblack/dsh-message-edit)；而会话 id 变化会破坏客户端窗口、引用与
用户心智模型。

**决定**

edit / retry / reroll 采用**就地编辑**语义：rewind 截断到目标轮之前的闭合 `turn/end` 边界，再 append
手工回合 / 重放输入回**同一会话**——session id 不变；只有 `fork` 派生新 id。

**考虑过的选项**

- **每次编辑派生新会话**：实现更简单（纯 append），但会话 id 变化会破坏客户端窗口、引用与用户心智模型，
  与产品语义不符。

**后果**

- rewind 必须支持 live 会话（截断 RDB 与内存 log、对齐 handle cursor、重置 agent 轮次游标），是 rdb 实现
  中最复杂的路径。
- 轮号复用、空轮吸收、assistant manualTurn、客户端投影重置等实现约束，以及各操作的完整语义见
  [设计 20260917-编排层操作语义](../designs/20260917-编排层操作语义.md) 的「就地编辑语义」。
- 会话不记录操作历史：版本效果事件与它的读侧投影都不存在，类型只作为历史形状保留在
  `@morlay/session-branch`（[ADR-20260920-删除版本树投影并停止写版本效果](../../../session-branch/.agents/adrs/20260920-删除版本树投影并停止写版本效果.md)）。
