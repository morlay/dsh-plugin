# 自造事件类型的信封：落库前补 `ignorable`，读回时兜底

状态：已实现（2026-09-24）。起因是一次真回归：`session-mode/selected`（会话模式的选择事件）落库后，
**写入**与**读取**都被上游的持久化校验拒绝——切换模式的会话打不开。

范围：`packages/session/session-rdb/` 的读写路径与 `OWN_EVENT_TYPES`（[`src/log.ts`](../../src/log.ts)）。
事件类型本身的语义（`session-mode/selected` 是什么）在
[`@morlay/dsh-session-mode`](../../../../profile/dsh-session-mode/README.md)。

## 上游的规则

上游 [`KNOWN_SESSION_EVENT_TYPES`](../../../../../vendor/deepseek-harness/packages/core/session/src/known-event-types.ts)
是**由上游仓库里 `SessionEventMap` 的声明生成的**：只有那些类型才是"已知"的。持久化校验
（`validateStoredEvents`）只放行两种事件——已知类型，或**带 `ignorable: true` 信封的未知类型**；
其余一律 fail loud（"很可能是更新的 harness 写的日志"）。

`ignorable` 是**落库那一刻**写进事件信封的标记（`SessionEvent.ignorable`），不是读取时的判断：它声明
"不认识这个类型的读者可以安全跳过它"。而外部插件的事件按构造就在上游的已知表之外——上游
`Session.append` 又没有承载这个信封的口子（它的第三个参数只服务 surface 事件），于是这一笔只能由
**持久化层**补。

## 决定

1. **落库前补信封**：`appendBatch` 在 `validateStoredEvents` 之前调 `sealOwnEvents(events)`——凡
   `OWN_EVENT_TYPES` 里的事件类型，落库的那一份带上 `ignorable: true`。canonical log 里的形状不变
   （live 会话的事件对象是冻结的，补的是 `materializeAppendBatch` 的 JSON 快照副本）。
2. **读回时兜底**：`needsShapeAdoption` 把"含自造事件类型"也算作需要归一的记录，`normalizeToCurrentShape`
   顺手给它们补信封。这一半修的是**补信封之前落库的历史数据**（同一个会话当时读不出来）。
3. **登记表就是白名单**：`OWN_EVENT_TYPES` 列出本仓库自造、上游不认识的事件类型——历史遗留的
   （`session-branch/version`）与当前在写的（`session-mode/selected`）都在其中。**新增自造事件类型必须
   登记**，否则写入就被拒；**不要**用"所有未知类型"代替（更新版本 harness 写的未知事件必须保持 fail loud）。

## 考虑过的选项

- **让事件类型进上游已知表**：那张表由上游仓库的声明生成，外部插件进不去（vendor 只读）。
- **读取时统一放行未知类型**：等于把"更新的 harness 写的日志"也读成残会话——上游拒绝这件事是对的。
- **绕开 `Session.append`，由写方直接构造带信封的事件落库**：历史做法（旧 `session-branch/version`，
  见 [它的 ADR](../../../session-branch/.agents/adrs/20260917-版本效果以ignorable事件原样落库.md)），但它要求
  每个写方自己碰持久化句柄；模式的选择事件本来就是 canonical log 的一部分（决定模型看到的工具与提示词），
  该走正常的 append 路径。

## 后果

- 自造类型在库里**自带信封**：非本仓库的读者（token meter、上游投影）凭它可以安全跳过。
- 新增自造事件类型多了一步：登记进 `OWN_EVENT_TYPES`。漏登记的症状是"写入就被拒"，判据钉在
  [`legacy-shape.spec.ts`](../../src/__tests__/legacy-shape.spec.ts)（写入含该类型的批次 → 读回 → 事件带
  `ignorable`）与真装配探针 `verify-session-mode.mts` 的"抽读已存会话"那条。
