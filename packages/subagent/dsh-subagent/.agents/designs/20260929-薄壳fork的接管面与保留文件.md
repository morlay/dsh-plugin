# 薄壳 fork 的接管面与保留文件（dsh-subagent）

状态：**已实现**（接管官方 `subagent` 行、保留文件与偏离登记都有守护）
范围：`packages/subagent/dsh-subagent/` 的接管面——行怎么被复用、保留哪几个文件、哪些结构性偏离是必须的、
配置页归谁；门面与用法见该包 [`README.md`](../../README.md)。
约束：上游只读。保留文件里指向未复制文件的 import 走相对路径指向 `vendor/deepseek-harness/packages/subagent/subagent/src/...`，
构建时内联进 `dist/index.mjs`（发布物自包含）。

## 结论摘要

| 议题     | 结论                                                                         | 一句话理由                                                                        |
| -------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 行复用   | 插 `{id: "subagent", name: "@morlay/dsh-subagent", config: {...}}`           | Loader 对同 id 复用同一个 Entry，行 id 与 settings namespace 都不用换             |
| 文案判定 | 按会话选：`composedPreset(parent.ctx)` 命中 `localizedReturnGuidancePresets` | 只有挂本部署 preset 的会话该看到中文，其余保持上游那套                            |
| 保留面   | 3 个文件（`continuation-messages` / `continuation` / `index`）               | 静态 import 链决定复制面：替换中间那份就得接管引用它的两个                        |
| 偏离登记 | `upstream-wiring.spec.ts` 的 `DELTAS` 表逐条登记                             | 偏离是同步纪律的守护面，片段没命中就红                                            |
| 配置页   | 全部留在**官方**那张卡上，本包没有 client 半                                 | 接管没换行 id；再注册一套 `settings.subagent` 字典会让 `locale.register` 直接抛错 |
| 格式化   | 三个保留文件排除在 oxfmt 之外（`.oxfmtrc.json`）                             | 它们与上游逐行对照是本包唯一的价值，重排就失去意义                                |

## 事实基线

### 接管面（装配）

行数据在本包 `./rows` 出口（`src/rows.ts` 的 `subagentRows()`）：插一条
`{id: "subagent", name: "@morlay/dsh-subagent", config: {localizedReturnGuidancePresets}}`——**按官方行 id 复用**，
Loader 对同 id 复用同一个 Entry、后者替换入口 options，所以行 id 与 settings namespace（namespace 就是行 id）都还是
`subagent`，官方设置卡（`ui-settings-subagent`）与它的服务行（`subagent-model-selection-settings`）都不动。
顺序前提：本包排在 `@deepseek-ai/dsh-base` 之后。

采用它的部署 bundle 是 [`@morlay/session-mode-profile`](../../../../bundles/session-mode-profile/README.md)：它按 `./rows`
展开行并给 `localizedReturnGuidancePresets: [mode-switch]`（app 的 `dsh.profile.bundles` 列的是那个 bundle）。
理由与被否的路线见 [`ADR-接管官方行按id复用而非换id`](../adrs/20260928-接管官方行按id复用而非换id.md)。

### 保留文件与复制面

薄壳 fork 只留**有意改过**的文件，其余上游文件不复制：

| 保留文件（`src/`）         | 保留什么                                                                           |
| -------------------------- | ---------------------------------------------------------------------------------- |
| `continuation-messages.ts` | 中文文案 + 判定函数 `localizedReturnGuidance`（"这个会话要不要本包那份文案"）      |
| `continuation.ts`          | 接线 + 调用点按会话选文案（读 `ctx.agentPresets` 的 `composedPreset(parent.ctx)`） |
| `index.ts`                 | 接线 + 装配面配置字段（`localizedReturnGuidancePresets`）+ 两处结构性偏离（见下）  |

静态 import 链决定了复制面：`continuation-messages` ← `continuation` ← `index`，要替换中间那一份就得连同引用它的
两个文件一起接管。原因、被否掉的路线与后果见
[`ADR-薄壳fork接管subagent行只改回报文案`](../adrs/20260923-薄壳fork接管subagent行只改回报文案.md)。

### 偏离登记（可执行）

`src/__tests__/upstream-wiring.spec.ts` 的 `DELTAS` 表逐条登记上面每处偏离（新增块、改过的行、装配面字段），
偏离表里的片段没命中就红——加偏离必须同时登记。

### 两处结构性偏离

- **`index.ts` 不复述 cordis 合并接口**：上游此处 `declare module '@deepseek-ai/cordis'` 声明 `Context.subagents`
  与 `subagent/*` 事件；本包 `import type {} from '@deepseek-ai/dsh-subagent'` 引用上游那一份（同形声明复述两遍
  会在同一个 program 里撞 `TS2717`）。
- **标准装饰器在构建期降级**：`@Remote(...)` 是 TC39 标准装饰器，rolldown/oxc 不降级它（上游管线里这步由 tsc
  完成），所以 `tsdown.config.ts` 里有一个 esbuild 预转换（vitest 侧用 devkit 的同一份，见根
  [`债务 vitest与构建需自行降级标准装饰器`](../../../../../.agents/debts/20260923-vitest与构建需自行降级标准装饰器.md)）。

### 配置面

**子代理用哪个模型不在这张卡上**：它跟着**父会话的模式**走（`@morlay/dsh-session-mode` 里「模式 → 服务商 / 模型」
那两个选择器）。

限额两个字段（`maxDepth` / `maxActiveSubagents`，标了 `.volatile()`）由**官方**那张设置卡承担：接管没换行 id，
`subagent` namespace 照旧，`ui-settings-subagent` 与 `subagent-model-selection-settings` 都不动。

本包**没有 client 半**：卡片由官方那行承担，再注册一套 `settings.subagent` 字典会让 `locale.register` 对同
namespace 同 locale 直接抛错（官方卡片那一行随之加载失败）。`Config` 的 `localizedReturnGuidancePresets` 是
**装配面**字段（`.hidden()`）：它不进设置页，由装配那一行给。

## 取舍

- **不换行 id、不自己注册 settings 字典**：换 id 会带走官方设置卡与它的服务行；注册同 namespace 的字典直接抛错。
- **只留 3 个文件、不整包复制**：整包 fork 会让上游每次升级都要人工对齐全部文件，而本包只改一处文案。
- **偏离用可执行清单守，不用注释守**：注释在上游改动时不会红。
- **保留文件排除格式化**：逐行对照是同步纪律的判据，重排后这条判据失效。
