# 设置页自建 client 半，并停掉官方两条入口行

状态：已采纳

本包接管官方 `subagent` 行后，设置页那张「Subagent」卡片（上游另一个包
`@deepseek-ai/dsh-client-ui-settings-subagent`，装配行 `ui-settings-subagent`）就落空了：它读的
settings namespace 是**行 id** `subagent`，而本部署那行已被禁用，namespace 不存在。同时我们希望那张卡片
是本包自己的样子——中文文案、标题「子代理」、**只有限额一段**。

## 考虑过的选项

- **把官方行换个 `name` 而不是插新行**（`- id: subagent` + `name: "@morlay/dsh-subagent"`）：namespace 仍是
  `subagent`，官方卡片照旧可用，client 半一行都不用写。否掉的原因是**文案锁在官方包里**：卡片标题、
  一句话说明、字段标签都来自它自己注册的 `settings.subagent` 字典，而 locale namespace 同名注册会撞
  （同 key 不能注册两份），我们改不了；它还把「模型白名单」段和限额段放在同一页，而那段本部署不要
  （见下）。另一个代价是偏离本包已确立的形态（禁用官方行 + 插 `subagent-fork`，见
  [ADR 薄壳 fork 接管 subagent 行只改回报文案](./20260923-薄壳fork接管subagent行只改回报文案.md)）。
- **不做设置页**（限额只能改部署配置）：官方已经有这个面的先例，而限额正是用户当场要调的值（递归深度、
  并行上限），所以这个选项被否。
- **自建 client 半 + 停掉官方两条行**（本决定）：卡片读本包行的 namespace `subagent-fork`，文案与结构
  都归我们；官方卡片行与它带的模型白名单服务行一起停掉。

## 为什么不做模型白名单

官方卡片的第二段读 `subagent-model-selection-settings` 行（`@deepseek-ai/dsh-tool-subagent/model-selection-settings`），
给 Agent 授权「可为子代理挑选的模型」。本部署不要这个能力：**子代理用的模型统一由 session mode 的
顶层 `models` 决定**（`@morlay/dsh-session-mode`）。留着那行只会让部署里多一个没人读的服务
开关，所以随卡片一起禁用——它原本被留着的唯一理由（官方 standard / ptc / cordis preset 的 `tool-subagent`
行带 `modelSelectionSettings: true`）也随官方 preset 整套被 `@morlay/dsh-profile` 禁用而消失。

## 后果

- **官方卡片行仍然禁用**：本卡注册到**本行的配置入口** `plugins.row.config`（key `<bundle>#<row>`，页面侧由
  `rowConfigKey()` 生成），与官方分组 `plugins.item` 不冲突。禁用官方行是产品决定——入口整体换成我们这份；
  顺带它也读不到自己的 namespace（它读的是官方行 id，而官方行在装配里已不存在）。
  早期版本本卡挤在 `plugins.item` 的同一 `id` 上，那时禁用是硬依赖：list 槽不接受第二个占用者，
  `ui-slots` 的 `register` 会直接抛 `already has an entry with id "subagent"`。无论哪种形态，
  [装配面测试](../standards/how-to-verify.md) 都盯着 patch 那两行。
- **locale namespace `settings.subagent` 与官方卡片同名**：两边都会 `declare module
'@deepseek-ai/dsh-client-ui-slots'` 声明同一个 key。官方包被禁用是本决定的直接依赖——哪天真要放回官方
  卡片，得先解决命名空间与文案的归属。
- **限额段的字段与下限照搬上游语义**：`maxDepth` ≥ 0、`maxActiveSubagents` ≥ 1，staged 编辑 + 保存/丢弃，
  非法草稿留在屏幕上并挡下保存（而不是被悄悄丢弃）。这些行为在**控制器层**有测试（假 scope + fork 的
  表单模型）。
- **组件渲染面无测试**：画卡片那段（`SubagentLimitsCard.tsx`）只过了构建，没有断言它渲染出什么——缺
  client harness 这件事见既有债务
  [对话 UI 客户端半的装配面缺测试辅助](../../../../session/ui-conversation-message-actions/.agents/debts/20260917-对话UI客户端半的装配面缺测试辅助.md)。
- **表单原语来自 fork 的包**：`@morlay/dsh-client-ui-primitives/client`（`SettingsForm` /
  `SettingsValueField` / `SettingsFormModel` / `settingsNumberField`）。上游官方那套 primitive 走
  CSS Modules，与本仓库的 css-in-js 层不兼容，所以走 fork 的那一份。
