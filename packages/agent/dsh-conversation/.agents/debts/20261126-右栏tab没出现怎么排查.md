# 右栏某个 tab 没出现，怎么排查

状态：排查入口（2026-11-26）。

症状只有三种，按顺序看一眼就能分岔：

| 现象 | 原因 | 查什么 |
| --- | --- | --- |
| 标签条里**没有**那个 chip | `tabs.register` 没跑（类型注册失败/被同批前一条抛错中断） | 控制台有没有 `already registered` / `no tab type is registered`；该行的 `onInit` 是否执行到 |
| 有 chip，点开是「这个标签的正文还没有注册」 | 正文注册的 **key 与 `definition.id` 不匹配** | 正文那条 `slots.register({ name:'sidebar.right.pane.tab', key })` 的 `key` 必须是类型的 `id`（不是 `kind`） |
| 都在，但视觉是裸的 | CSS 没内联 | 产物里该包的 `*.module.css` 是否进了 `__$dsh_client_module_manifest`；`just custom build` 的前端产物 |

两条前置事实（已验证，别重复怀疑）：

- **顺序不是问题**：`slots.inject` 会订阅声明变化、就绪即装（判据 `zephyr-app` 的 `slots-late-declaration.spec.dom.ts`）；
- **声明方是 `RightbarSeat` 的 children**：`sidebar.right.pane.tab` / `.title` 由 `rightbar.session` 的注册声明，上游行（terminal / browser / files / preview）都往这两个名字注册。

探针（真跑时）：

```js
document.querySelector('[data-sidebar-right-panel]')?.innerHTML.slice(0, 1200)
```
