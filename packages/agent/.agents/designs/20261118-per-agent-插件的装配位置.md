# per-agent 装配：Provider 声明 scope，装配器按 scope 过滤

状态：形态已定，待实现。
范围：`@Injectable()` 的 scope 声明、装配器如何按 scope 分派、事件字段绑哪个 ctx、删掉哪几处自造机制。
非目标：上游 `AgentSetup` 的调用细节（见上游 `core/agent/src/index.ts:54`）、`AgentLoop.create` 那条路径（已记债）。

## 一、决定

| # | 决定 |
| --- | --- |
| 1 | **Provider 自带 scope 声明，值是 symbol 不是字符串**：`@Injectable({ scope: ScopeAgent })`。
`export const ScopeRoot = Symbol.for("morlay.zephyr.scope.root")` / `export const ScopeAgent = Symbol.for("morlay.zephyr.scope.agent")`。
**为什么是 symbol**：字符串会拼错（`"agnet"`）且无法穷举；symbol 是唯一身份、可作键、`Symbol.for` 让跨包同形（与仓库既有 `kAgentScoped = Symbol.for("morlay.dsh-agent.agent-scoped")` 同一手法）。 |
| 1b | **`@AgentScoped()` 是 `@Injectable` 的别名**：`AgentScoped()` ≡ `Injectable({ scope: ScopeAgent })`。留一个装饰器名做**可读性**（写在域里比 `@Injectable({ scope: ScopeAgent })` 短），但**不留第二套语义**——它没有额外行为，也不产生额外标记。 |
| 2 | **装配器按 scope 过滤**：装清单时把 `scope: "agent"` 的挑出来，在**每个 agent 的 `agentCtx`** 上装（上游钩子 `CreateAgentOptions.setup`）；`scope: "root"`（默认）的照旧装应用。 |
| 3 | **删掉 `AgentProviderGroup` 与 `entries` 手写清单**：它全仓零读取、与「Provider 自己声明」是同一件事的两份写法。6 个 `provideXxx()` 里的条目随之移除。 |
| 4 | **`@AgentScoped()` 不再是「标记」**：语义从「打个 tag 让诊断能指出」变成「这个 Provider 由 per-agent 装配器装」，与 `scope: "agent"` 同一件事，两者留一个（倾向只留 `scope`，删 `@AgentScoped`）。 |
| 5 | **事件字段绑「该行装配时用的那个 ctx」**：`agentCtx` 上装的行 → 令牌的 `bus` 就是 `agentCtx` → 订阅落在该 agent 的 scope。**不需要显式传 ctx**（`onIn` 那条设计作废）。 |
| 6 | **`mountRow` 与 `bootstrapApplication` 走同一个「装一行」实现**：注入查 `instances`、事件字段绑当前 ctx——两处都调它，per-agent 装配也调它。 |

## 二、为什么这样最简

- **一个事实一个 home**：Provider 自己说 scope，装配器只按它分派；没有清单、没有第二处列举、没有「声明说 agent、实际装 root」的裂缝。
- **与上游同形**：上游在 `agentCtx` 上 `ctx.plugin(scope)` 就是「装进该 agent 的 scope」，我们只是把「哪些 Provider 该装进去」从**手写条目**换成**Provider 自带的声明**。
- **不需要新 API**：没有 `onIn`、没有 `AgentProviderGroup`、没有 `scopeOf` 的运行时判断——`scopeOf` 可降级为纯诊断。

## 三、已知要一起销的两笔

1. `mountRow` 现在**不给 `EventEmitter` 字段绑 ctx**（只处理 `injectPlaceholderOf`）→ 用它的行一调 `on(...)` 就抛「装配完成前被使用」。决定 6 顺带销掉。
2. `bootstrapApplication` 给事件字段绑的是**根 ctx**（`bootstrap.ts:527`），与 `event-emitter.ts:69` 注释的「本行 ctx」不符。决定 5 + 6 顺带销掉；`42359932` 补的三条 disposer 届时可重新评估。

## 四、迁移面

- 6 处 `extends AgentProviderGroup` → 删；对应 Provider 改标 `scope: "agent"`；
- 6 份 `provideXxx()` 里移除这些条目（它们不再装 root）；
- 2 处手写订阅（`tool-guidance.service.ts:179` / `session-mode.service.ts:539`）→ 各做成 `scope: "agent"` 的 Provider，`inject` 它的域直接用；
- `zephyr` 的装配器：`fillInjections` 加事件字段绑定 + 按 scope 过滤 + 每 agent 调一次。
