## 轨迹：装配完整，缺"有内容的会话"

```
slots.entries("conversation.view") → [{ id: "chat", order: 0 }, { id: "trajectory", order: 10 }]
```

两条都在、都带 label 函数。主区看不见 tab 栏是因为会话是 **blank**（显示 hero）。
发一条消息就有内容——而这条要可用的模型：

```
remote.session.modelCatalog(...) → { default: { provider: "deepseek-official", model: "deepseek-flash" },
                                      routableProviders: [], groups: [], failures: [] }
```

`groups` 为空，即这个部署没配 provider（需要 API key）。这不是接线缺口。

## 排查时踩过的坑

- `agent-browser` 必须带 `--args "--no-sandbox"`；
- `window.__dsh.app` 是**客户端** app，它的服务表里没有宿主侧服务是正常的；
- `rg` 的 `-r` 是「替换」，`rg -rn "pat"` 会把输出替换成 `n`——不要用；
- 真机 console 里 `[dsh] 客户端装配失败` 一定先看，白屏基本都是那一行。
