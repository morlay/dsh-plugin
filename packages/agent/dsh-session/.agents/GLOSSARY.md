# 会话数据面（`dsh-session`）

会话的事件日志、投影、查询与计量怎么称呼：**本包是这些词的定义者**，其他包只引用、不改写。
上游的会话机制归上游（_上游概念_：session / turn，真源 `vendor/deepseek-harness/docs/subsystems/session.md`）；本表定义的是本仓数据面的说法。上下文边界见[定义权地图](../../../../.agents/GLOSSARY-MAP.md)。

## 术语

### 会话与轮次

**会话（Session）**：
由事件日志与投影构成的对话实体，以会话标识寻址；存储、投影、查询与计量都只认这个实体。
_避免使用_：对话、聊天记录

**轮次（turn）**：
从 turn/start 到 turn/end 的对话回合：一条用户消息与若干助手消息。
_避免使用_：回合、round

**闭合边界（closed boundary）**：
已落定 turn/end 的轮次边界——派生新会话的唯一合法锚点；截断另接受「用户消息之前」（不含该消息）与「空前缀」两种锚点。
_避免使用_：检查点、checkpoint

### 事件

**ignorable 事件**：
带「可跳过」信封、读者可以安全跳过的事件：**原样落库**，读侧凭信封决定是否参与投影。本仓自造的事件类型也必须按这条规则登记（漏登记会让整个会话打不开）。
_避免使用_：瞬时事件（瞬时事件是另一概念）

**版本效果（version effect）**：
旧日志里记录一次分支操作（编辑 / 重试 / 重掷 / 派生 / 截断）的事件类型；本仓**不再产出**它，读侧只用来识别既有会话里的这一类事件。
_避免使用_：版本事件、变更记录

### 会话状态

**live 会话**：
驻留内存（会话注册表里有 owner）的会话：截断就地作用在内存日志上，并复位派生缓存、对齐读游标与继承前缀。
_避免使用_：活动会话、打开中的会话

**cold 会话**：
只有持久化、没有内存 owner 的会话：截断之后要经加载重新接管。
_避免使用_：离线会话、已关闭会话
