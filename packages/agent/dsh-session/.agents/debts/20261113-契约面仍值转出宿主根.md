# 契约面仍按值转出宿主根（`dsh-session`）

状态：已知未销账——`@deepseek-ai/dsh-session` 宿主根上的值仍经 `./contract` 转出；当前**没有**生产浏览器路径能到这里，但离越界只差一条 import
范围：`packages/agent/dsh-session/src/contract/*.ts` 里对上游宿主根的**值**转出，以及为什么先不动它们
非目标：`./endpoint`（那里已经 client-safe：`session-id.ts` 走 `@deepseek-ai/dsh-session/types`）
关联：设计 20261028-包内子域拆分与注册抽象（面矩阵）· [dsh-conversation 的对话域边界](../../../dsh-conversation/.agents/designs/20261109-对话域边界与交付物归属.md)（同一条 client-safe 判据）

## 一、事实

`./contract` 是**进程内端口**面，其中这些语句按**值**引上游宿主根（`@deepseek-ai/dsh-session`）：

| 文件                                  | 值                                                                                                            |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `contract/session.contract.ts`        | `Session` / `SessionId` / `SessionSeq` / `SessionLogOffset` / `SESSION_FORMAT_VERSION`                        |
| `contract/session-log.contract.ts`    | `interruptedTurnClosers` / `snapshotSessionEvent`                                                             |
| `contract/session-query.contract.ts`  | `SessionQueryEngine` / `SessionQueryError`（上游 `dsh-session-query` 根）                                     |
| `contract/session-format.contract.ts` | `sessionFormatLogFilename` / `parseSessionFormatLogFilename` / `sessionFormatCatalog`（上游两个 format 包根） |

## 二、为什么现在是安全的

判定标准不是"有没有值转出"，而是"契约面在不在 **client 图**里"。当前 client 图（`apps/zephyr-custom` 的静态面）里没有 `@morlay/dsh-session/contract`：浏览器半取会话身份走 `@morlay/dsh-session/endpoint`（`SessionId` 从 `.../types` 铸造）。`just custom build` 绿、产物里没有上述标识，就是这条判据的证据。

## 三、越界的样子与销账形态

- **症状**：任何 `src/ui` / `apps/*/src/client` 的文件 `import ... from "@morlay/dsh-session/contract"`（哪怕只取一个类型，只要写成值导入）→ 上游 `core/session` 宿主根进图 → vite 把 `node:path` 映到 node-stub → `MISSING_EXPORT`，构建立刻红（不是"体积大一点"）。
- **销账**：把上表的**值**移到包根（`src/index.ts`，宿主面），`./contract` 只留 `import type` / `export type`；消费方从包根取这几个值。做完后 `grep -rn 'export {[^}]*} from "@deepseek-ai/dsh-session"' packages/agent/dsh-session/src/contract` 应为空。
- **为什么没顺手做**：这些值有多个宿主消费方（store / 投影 / 持久化 / 测试），且当前不阻塞任何验收；一次只动一条已验证的边界（`dsh-conversation`），比把两包的契约面一起翻更稳。
