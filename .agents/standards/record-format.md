# 记录格式

记录（设计 / 决策记录 / 债 / 术语表）、规格与票据是施工依据，不是写作练习。**格式骨架与命名的唯一 home** 是
[`zephyr-design`](../skills/zephyr-design/SKILL.md) 的模板；这里只给可判定的验收判据。

## 判据

| 判据                                                     | 怎么查                                                                                 |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 文件命名 `YYYYMMDD-<slug>.md`，无序号                    | `ls <层>/.agents/designs` 人工看                                                       |
| H1 就是标题本身，不带日期、不带序号                      | 评审人工                                                                               |
| 第一屏四行：状态 / 范围 / 非目标 / 关联                  | 评审人工                                                                               |
| 小节名照模板，不另创                                     | 评审人工                                                                               |
| 只描述现状：不出现「已废弃 / 被 X 取代 / 迁移自 / 原来」 | `grep -rn "已废弃\|被.*取代\|迁移自" .agents packages/*/*/.agents apps/*/.agents` 为 0 |
| 同层引用写短名，跨层给相对链接（目标用完整文件名）       | 评审人工点开链接                                                                       |
| 术语用定义它的包的词，引用不复制定义                     | 对照[定义权地图](../GLOSSARY-MAP.md)                                                   |
| 每条判据可判定：挂命令、用例名或可观察结果               | 评审人工；挂不上的说明接口还没想清                                                     |
| 格式没跑偏                                               | `pnpm exec oxfmt --check .`                                                            |

## 写法

- **第一屏给结论**：标题下四行 → 决定表；读者只看第一屏就能决定要不要往下读。
- **每节首句是这节的结论**；段落不超过三行，超了就是没想清，或者该用表。
- **一个事实一个 home**：写之前先找它现在在哪，找到就改那一份；别处要用就链接（home 表见 [`AGENTS.md`](../../AGENTS.md)）。
- **图只在关系确实比句子短时用**：图与表不重复同一份事实。
