# 规范（standards）

**项目 / 包特有**的规范（某个包的接缝、判据、环境门控）写在那**包**的 `.agents/standards/`。

## 规矩

- **一个判据只有一个 home**：通用判据在这里，包 / 项目特有的在该包 `.agents/standards/`；
  `README.md`、设计、ADR、技能里都不复述，只链接（home 表见 [`AGENTS.md`](../../AGENTS.md)）。
- **判据必须可判定**：每条给命令、用例名或可观察结果；给不出判据的句子不是规范，是背景知识，删掉。
- **规范写「必须 / 不许 / 一律」，不写流程**：何时做、怎么做归 [`.agents/skills/`](../skills)。
- **技术栈与版本见 [`mise.toml`](../../mise.toml)，命令入口见 [`justfile`](../../justfile)**（`just --list`）——
  这里不复制清单，也不索引命令。
- **规范冲突时按各层 [adrs](../adrs) 的决策走**；要改规范，先改这里再改代码。
