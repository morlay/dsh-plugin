状态：已实现（同步链、门禁与适配改动都已落地；遗留一条待复现的运行时现象，见「开放问题」）
范围：`DEEPSEEK_HARNESS_VERSION` 从 `0.2.2-rc.1` 提到 `0.2.2-rc.2` 这一跳里，上游改动对**本仓库自有面**（vendor 步骤、本地补丁、插件包、profile 装配）的影响与取舍。上游包内部的重构不在本文讨论范围。

## 结论摘要

## 事实基线

- 版本常量：`mise.toml` 的 `DEEPSEEK_HARNESS_VERSION = "0.2.2-rc.2"`；vendor 检出 `ddac96760b`（tag `dsh-v0.2.2-rc.2`）。
- 包清单变化（`git -C vendor/deepseek-harness ls-tree … packages`）：删 `api/account-controller`、`credentials/deepseek-account-platform`、`document/office-to-pdf`、`experimental/{agent-team,agent-team-profile,client-ui-agent-team,tool-agent-team}`、`web/web-search-{exa,perplexity}`；增 `client/ui-account-notifications`、`client/ui-agent-team`、`document/{office-kit,tool-office}`、`experimental/terminal-panel`、`mcp/mcp-manager`、`team/{agent-team,tool-agent-team}`、`util/{error,ripgrep}`。
- 上游 subagent 内部重构规模：`git diff --stat 66491b05e3 ddac96760b -- packages/subagent` 109 个文件、+4217/−2700；`internal.ts` 改名 `names.ts`（内容不同），`CreateAgentOptions` 收掉 `parentAgent`，`SubagentActivationSpec` 把 `request` 摊平，宿主投递改为公开的 `prompt` Remote。
- 我们的 subagent fork 的真实定制（`oxfmt` 对齐后 diff）：`packages/subagent/dsh-subagent/src/index.ts` 143 行、`packages/subagent/dsh-subagent/src/manager.ts` 80 行，全部是「按会话选中文回报指引」与「中文委派范围说明」两件事。
- 生成物依赖面：`vendor/deepseek-harness/packages/*/*/lib/typert.host.ts` 共 39 份、都 `import { z } from 'zod'`；其中 38 份的 `package.json` 声明了 `zod`，`@deepseek-ai/dsh-web` 没有（上游 HEAD 的 `packages/web/web/package.json` 依赖段同样没有它）。补齐后 `web/web/node_modules/zod` 指向 `node_modules/.pnpm/zod@4.6.6`，产物可直接 import（实测 `loaded: TYPERT`）。
- 门禁：`just test` 1496 passed / 9 skipped；`just lint` 0 warnings 0 errors（含 `check-locale`、`check-docs`）；`just build` 通过。

## 取舍

- **不逐点合并上游 `manager.ts` 的改动**：那是 1600 行级的重构（`Activation` 形状、命名预留 `SiblingNameReservations`、结算与投递路径都换了），逐点改必然漏，且难验证。改为「上游文件复制进来 + 重放定制」，定制面被压缩到 220 行以内，测试（`src/__tests__/` 15 个用例）覆盖的就是那两件事。
- **不保留 `internal.ts` 的符号投递**：仓库内没有第二处使用 `queueHostSubagentPrompt` / `steerHostSubagentPrompt`（`grep` 只在 vendored 目录命中），rc.2 又把它转成了公开 Remote，保留私有符号只会挡住升级。
- **不给 Office 工具写中文说明**：Office 面在本部署不装配（桌面宿主挂载 + `coding` 模式名单收口），写说明等于给一条用不到的路径付维护成本。
- **zod 统一到上游钉的 `4.6.6`**：`dsh-session-mode` / `dsh-subagent` 原来写 `4.4.3`，与上游大量包钉的 `4.6.6` 并存会让 `ZodType` 出现两份物理副本（TS2739），装到同一版本后消失。

## 开放问题

- **桌面 ADR 与 overlay 的既有不一致**：`packages/desktop/dsh-desktop-host/.agents/adrs/20260928-桌面档不含登录与账号面.md` 的「决定」写着停 `deepseek-account` / `account-controller` / `llm-deepseek-account` / `ui-settings-account`，而 `config/desktop.cordis.patch.yml` 实际只停 client 面（`ui-settings-account`、以及这次新增的 `ui-account-notifications`）。这一条早于本次同步存在，本次只更新了文档里的上游路径与包名，没有改动取舍；要么把服务端那几行也停掉，要么把 ADR 的决定改写成现值——留给下一次桌面档的改动定。
