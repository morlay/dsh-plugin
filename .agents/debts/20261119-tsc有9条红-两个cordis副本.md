# 债：`tsc` 有 9 条红，真因是 cordis 的模块增强用**相对 specifier**

状态：未销账。**`vitest` 全绿但 `tsc` 红**——`vitest` 走 esbuild strip、不做类型检查，所以绿是假象。
（`just lint` 里的 tsgolint 走的是同一套 program，所以它也红——见「不修的理由」。）

## 现象

`pnpm exec tsc --noEmit -p tsconfig.json | grep '^packages/'` 有 9 条，全是同一类：

- `bootstrap.ts` ×2、`scoped-rows.spec.ts` ×1、`dsh-{job,ptc,sandbox,skill}` 的 spec ×4 —— `Context` ↔ cordis `Context` 的单层断言报 **TS2352「两个类型不够重叠」**；
- `session-mode.service.ts` ×1 —— TS2375（`reasoningEffort` 的精确可选属性）。

## 真因（上一版记的「两个 cordis 副本」是错的）

`@deepseek-ai/cordis` 只解析到**一个**副本（`vendor/deepseek-harness/vendor/cordis`，`pnpm` 的 `link:` 指向它，`require.resolve` 也确认）。
真正的问题是 `Context` 的**模块增强写在相对 specifier 上**：

```ts
// vendor/…/cordis/src/events.ts:34
declare module './context.ts' { export interface Context { emit(…) … } }
// vendor/…/cordis/src/fiber.ts:10
declare module './context.ts' { export interface Context extends Pick<Fiber, 'effect'> { fiber: Fiber } }
```

而我们的代码 `import type { Context } from "@deepseek-ai/cordis"`（**包名**）。
TS 把「`./context.ts`」与「`@deepseek-ai/cordis`」当成**两个模块**，于是裸包名拿到的 `Context` 是**没有增强的基础版**
（缺 `emit` / `set` / `accessor` / `mixin` / `fiber` 那 9 个成员）→ 与任何真正用过增强的地方对不上。

## 为什么修不了

1. **改 vendor 是红线**（`AGENTS.md`：上游 `@deepseek-ai/*` 不可修改）——正确修法是把那两处 `declare module './context.ts'` 改成
   `declare module '@deepseek-ai/cordis'`，或让 `index.ts` 里先 `import './events.ts'` 再 re-export（都是上游的事）；
2. **我们的代码统一用深路径**（`@deepseek-ai/cordis/src/context.ts`）能绕开，但那把「用哪个 specifier」变成全仓纪律，
   且与上游其它包（它们都写裸包名）不一致——**制造第二套约定比这 9 条红更贵**；
3. `tsconfig` 的 `paths` 救不了：增强的 specifier 是相对路径，`paths` 只影响裸包名的**解析目标**，不改「两个 specifier 是两个模块」这个判定。

## 销账条件

Done when：`pnpm exec tsc --noEmit -p tsconfig.json | grep -c '^packages/'` = 0。
路径有两条：(a) 上游把模块增强的 specifier 改成包名（`dsh-v0.2.2-rc.3` 之后的下一次同步）；
(b) 我们把全仓的 `import … from "@deepseek-ai/cordis"` 统一改成 `…/src/context.ts`（要先说服自己这不会长出第二套约定）。

## 不修的理由

行为是对的（1795 用例全绿、`just custom dev` 无异常），缺的是**类型面的一致性**；而两条修法一条踩红线、一条制造第二套约定。
**在修好之前 `tsc` 不能单独作为门禁**——`just lint` 的 tsgolint 会连带红，所以门禁以 `just lint` 的 oxlint 部分为准，
类型面靠 review 与这条债盯着。
