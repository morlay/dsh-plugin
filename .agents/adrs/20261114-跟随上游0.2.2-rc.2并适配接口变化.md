# 跟随上游 0.2.2-rc.2 并适配接口变化

状态：已采纳——`mise.toml` 锁 `0.2.2-rc.2`（tag `dsh-v0.2.2-rc.2` @ `ddac96760b`），31 个插件包的 `engines.dsh` 同步到 `>= 0.2.2-rc.2 < 0.2.3`
背景：上游处于预发布、无兼容承诺。rc.2 带来两类变化：agent-team 三个 `experimental/*` 包转正为 `@deepseek-ai/dsh-agent-team` / `dsh-tool-agent-team` / `dsh-client-ui-agent-team`；以及 `SubagentRegistry` / `AgentDirectory` / `SandboxPolicy` / `Web` / `SessionQueryEngine` 的成员表变化、`SubagentPromptRequest` 收紧、`subagents/interruptByParent` 改为 `interruptByUser`。停在 rc.1 会缺这些接口，后续升级的差异只会更大。

**决定**

跟随 rc.2，并按「本仓只做适配、不改上游」逐项对齐：

- 版本与兼容：`mise.toml` 改 `0.2.2-rc.2`；所有插件包 `engines.dsh` 写 `>= 0.2.2-rc.2 < 0.2.3`（由构建环境推导的口径，当前手写，构建插件接入后自动写回）。
- 包转正：本仓 `dsh-agent-team` 的依赖与 import 改到 `@deepseek-ai/dsh-agent-team` / `dsh-tool-agent-team` / `dsh-client-ui-agent-team`。
- 契约补齐：`SubagentRegistry` 删 `drainChildren` / `interruptByParent` / `list` / `listChildren` / `waitForChildren`，补 `rootOf` / `namesOf` / `resolveName` / `waitForTreeWork` / `interruptByUser`；`AgentDirectory` 删 `isOwnedBy` / `roots`；`SandboxPolicy` 补 `registerWritableRoot`；`Web` 补 `listProviders` / `typertRemote`；`SessionQueryEngine` 补 `inspectSession`。
- 端点与类型：`subagents/interruptByParent` → `interruptByUser`（单命名参数 `childSessionId`）；`SubagentPromptRequest` 去掉 `parentSessionId` / `mode`，内容片段直接取上游类型。
- 声明与类型面：`AdaptedClass` 从 `@morlay/zephyr/compat` 导出（否则 129 处声明报 TS2883）；`SessionFormatCatalog` 从 `@morlay/dsh-session/contract` 导出；`WorkspaceId` 的类型与铸造函数拆到 `workspace-id.ts`（契约面只 re-export 上游 `/types`，避免 typert 解析本地别名失败）。
- 依赖与测试：`dsh-storage` 的 `zod` 对齐到上游 `storage-domain` 的 `4.6.6`；`dsh-sandbox` 的 3 份跨域 spec 迁回各自 owner（`dsh-agent-loop`），删掉 `devDependencies → @morlay/dsh-agent-loop`，包级环因此消除（未用 `ignoreWorkspaceCycles`）。

**考虑过的选项**

| 选项                                  | 否掉的理由                                                                 |
| ------------------------------------- | -------------------------------------------------------------------------- |
| 停在 `0.2.2-rc.1`                     | 缺 rc.2 的接口与修复；下一次升级的差异更大，且本仓契约会继续按旧成员表写   |
| 跳过 rc.2、等正式版                   | 上游预发布无兼容承诺，等待期间无法使用新能力；且 rc.2 是本轮同步的明确目标 |
| 用 `ignoreWorkspaceCycles` 绕过包级环 | 会把新环一并掩盖，且递归命令按任意顺序执行；环必须从依赖图消除             |

**后果**

- 上游三个 assets 出口（`dsh-client-ui-brand-official` / `dsh-client-ui-chat` / `dsh-client-ui-settings-account` 的 `./assets/*`）仍无源码面，patch 阶段保持 `lib` 形态；消费方不能按源码面引它们。
- 31 个包的 `engines.dsh` 现在是手写；构建插件接入后应改为构建期写回，避免再次漂移。
- `dsh-agent-loop` 的 PTC 执行器互斥 spec 仍未补（需真装配清单，见该包开放项）。
- 升级后的门禁：`pnpm -r --filter './packages/*/*' exec true` 无环；`just build` 全包通过；`just lint` 0 error；全仓 vitest 0 failed；`just custom build` 通过。
