# 引用展开拆成独立包并按 profile 装配

状态：已采纳

背景：`packages/context/dsh-context` 原是一个包六个出口，其中 `reference`（用户消息里的
`@path` / `skill:name` 在 `agent/pre-step` 展开成注入内容）与其他五个不是一类：

- 它**不依赖注入通道**——自己挂 `agent/pre-step`，`inject` 只有 `skills`，从不读 `ctx.contextAssembler`；
- 它复用的引用解析（`findReferences` / `parseReferenceToken`）的 home 是
  [`@morlay/dsh-client-ui-primitives`](../../packages/client/ui-primitives/src/reference.ts)（client 与 host
  共用一份，见 [ADR-20260917-引用的统一解析与渲染转换](../../packages/session/ui-conversation-message-actions/.agents/adrs/20260917-引用的统一解析与渲染转换.md)），
  而那份包同时带 client 样式层与 React 渲染——于是发布出去的 host 能力在依赖清单里拖着一个 client 包；
- 装配上它被绑在 preset 的 `isolate` 通道组里，只有 `coding` 装它（`chat` 用 `capabilities` 裁掉）。

**决定**

三件事一起做：`@morlay/dsh-context` 改名 **`@morlay/dsh-context-assembler`**（一个包五个出口，只剩依赖通道的
那些）；引用展开独立成 **`@morlay/dsh-reference`**，它复用的解析实现**构建时内联**（devkit 新增 `inline`
选项，发布清单里不出现 `@morlay/dsh-client-ui-primitives`）；装配改由
[`@morlay/better-session`](../../packages/session/better-session/cordis.patch.yml) 插一行，不再经过 preset 的
通道组。

## 考虑过的选项

- **把解析实现搬进 `dsh-reference`**：解析是 client 与 host 共用的一份（渲染转换认的就是它的产物形态），搬走
  要么出现第二份实现，要么让 client 反向依赖 host 包。
- **解析继续走 external、照旧声明依赖**：消费方为一条 host 能力装 client 样式包，正是要摆脱的东西。
- **仍由组装出口装它（组装包依赖新包）**：装配面确实还是一行，但包边界没解决——组装包仍拖着 host 能力，
  `capabilities` 也仍要替 `chat` 记住「reference 要被裁掉」。
- **`dsh-reference` 放在 preset 组内单独一行**：它不需要通道，放进组里只是白继承组语义；通道组里只该有组装行
  （[ADR-20260922-通道与注入行按模式isolate装配](../../packages/profile/dsh-agent-preset/.agents/adrs/20260922-通道与注入行按模式isolate装配.md)）。

## 后果

- 引用展开**各模式都生效**（`chat` 也有）：收口改由它自己的判据承担——没有 `read` / `skill` 工具就不展开
  （[`src/index.ts`](../../packages/context/dsh-reference/src/index.ts) 的 `hasTool`）。
- 产物里有一份解析实现：源码仍唯一（ui-primitives 的 `reference.ts`），但 ui-primitives 与 dsh-reference
  各产一份——升级解析后要**重新构建并发布** dsh-reference，光发 ui-primitives 不会带到 host 侧。
- devkit 的 `inline` 从此是包级构建约定（`inline: ["<pkg>"]`），命中的包不进 `package.json` 依赖清单；
  新消费方加一行即可，判据有单测（`devkit/src/__tests__/inline-deps.spec.ts`）。
- preset 的组装行名与 `capabilities` 名单更新（少一个 `reference`）；`patch.spec.ts` 仍只钉「通道组内只有组装行」。
