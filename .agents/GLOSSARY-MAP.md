# 定义权地图

一个概念只有一个定义处：**定义它的包持有它，别处只引用**。这张表回答三件事：概念归谁、定义在哪、其他包怎么用它。

## 规则

- **词只定义一次**：定义它的包持有；别处要用就链接过去，不复制定义、不换说法。
- **`GLOSSARY.md` 只放术语**：不放规范、不放设计理由、不放实现说明（各自的 home 见仓库根 [`AGENTS.md`](../AGENTS.md) 的 home 表）。
- **新语言边界**：某个包开始有一套自己的词，就在**那个包**的 `.agents/` 下立表，再在上一节加一行；只有实现、没有自己语言的包不立。
- **上游概念不由本仓定义**：必须提「与上游的关系」时标注「上游概念」并给上游真源（`vendor/deepseek-harness/docs/`，流程见[上游同步技能](./skills/zephyr-upstream-sync/SKILL.md)）；本仓的说法是运行模式（mode）、装配清单、装配行、扩展、宿主装配面、工作区配置、部署值。
