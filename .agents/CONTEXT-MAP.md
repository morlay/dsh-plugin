## 规则

- **词只定义一次**：两个以上包要用的词 → 根 `.agents/CONTEXT.md`；只在一个上下文里有意义的词 → 那个包
  `.agents/CONTEXT.md`。别处要用就链接过去，不复制定义、不换说法。
- `CONTEXT.md` **只放术语**：不放规范、不放设计理由、不放实现说明（各自的 home 见仓库根
  [`AGENTS.md`](../AGENTS.md) 的 home 表）。
- 出现新的语言边界（某个包开始有一套自己的词）就在表里加一行，并在那个包的 `.agents/` 下立
  `CONTEXT.md`；只有实现、没有自己语言的包不立。

## 关系

- **工具说明 → 上下文注入**：`profile/dsh-tool-guidance` 的包根（即工具说明运行时）自己分三档送达——工具投影改写
  （`system-prompt/assemble` 上换汉化短描述、剥掉参数说明）、`base` 组正文由**本行自己挂 `agent/pre-step`** 常驻
  （同键正文相同就不重发）、其余三组注册进官方 `ctx.skills` 由官方 `tool-skill` 列目录按需加载（`config.groups: false`
  可整档关掉；本部署三个模式里没有关它的——`chat` 靠 `allowTools` 收窄与推导出的 `skills: false` 自然没有目录可列）；通道
  （`ctx.contextAssembler`）只剩抑制被吸收的上游段（`suppressSection`）这类改写，不再代为送达正文（单向：通道不引用注入方）。决策见
  [ADR-提示词注入只有一个通道且按需内容走skill](../packages/context/dsh-context-assembler/.agents/adrs/20260921-提示词注入只有一个通道且按需内容走skill.md)，
  送达形态见 [设计 工具说明与用法分组的送达](../packages/profile/dsh-tool-guidance/.agents/designs/20260929-工具说明与用法分组的送达.md)。
- **会话编辑 ↔ LLM 适配**：无依赖。两者都作为 cordis 插件装配进 DeepSeek Harness，但互不引用（会话编辑经
  `agents` 服务 duck-typed 驱动重放，不经过 LLM 适配器）。
- **可配置沙箱 ↔ 其余**：无依赖。它只替换官方的进程沙箱与文件系统服务，并按 agent 作用域覆盖两条运行时上下文
  （`sandbox:policy` / `approval:policy`）。
- **会话编辑内部**：契约层 `@morlay/session-branch` → 编排层 `@morlay/ui-conversation-message-actions` →
  实现层 `@morlay/session-rdb`；装配决策（禁用官方 jsonl、rdb 替换）归聚合层
  `@morlay/better-session`（`cordis.patch.yml` 与
  [ADR-20260917-rdb替换官方jsonl持久化](../packages/bundles/better-session/.agents/adrs/20260917-rdb替换官方jsonl持久化.md)）。
- **对话 UI 扩展 → 会话编辑**：官方对话外壳行提供槽声明与渲染，编排层的 client 半在它上面做槽位替换与覆盖，
  `client/ui-primitives` 随用到它的 client 行内联提供样式与输入基础（边界与放弃的能力见
  [ADR-不fork上游前端组件只做插槽扩展](./adrs/20261001-不fork上游前端组件只做插槽扩展.md)）；
  `context/dsh-reference` 的引用展开不依赖通道服务（`inject` 只有 `skills`），装在同一 profile 的
  `@morlay/better-session` patch 里，因此各模式都生效——chat 模式靠「没有 `read` / `skill` 工具就不展开」自然收口。
- **仓库 → 上游**：`vendor/deepseek-harness/` 是上游按版本克隆的 side workspace（`DEEPSEEK_HARNESS_VERSION`
  锁定），本仓库所有包经 `workspace:*` 解析到该固定版本源码（见
  [ADR-上游以side-workspace版本锁定完整代码而非发布版本](./adrs/20260917-上游以side-workspace版本锁定完整代码而非发布版本.md)）。
